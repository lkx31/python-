# str、tuple、list 三容器记忆卡片

> **一句话核心：字符串用引号，元组用圆括号，列表用方括号；字符串和元组不可变，列表可变。**

---

## 一、核心区别总表

| 对比项       | str 字符串                      | tuple 元组                 | list 列表              |
| ------------ | ------------------------------- | -------------------------- | ---------------------- |
| 定义符号     | `'abc'` / `"abc"` / `'''abc'''` | `(1, 2, 3)`                | `[1, 2, 3]`            |
| 是否可变     | **不可变**                      | **不可变**                 | **可变**               |
| 元素类型     | 只能是字符                      | 任意类型                   | 任意类型               |
| 是否有序     | 有序                            | 有序                       | 有序                   |
| 是否支持索引 | 支持                            | 支持                       | 支持                   |
| 是否支持切片 | 支持                            | 支持                       | 支持                   |
| 单元素写法   | `'a'`                           | `(10,)` 必须有逗号         | `[10]`                 |
| 典型用途     | 文本数据                        | 固定数据、保护数据不被修改 | 存储可增删改的多个数据 |

**记忆点：**

- `str` 和 `tuple` 一旦创建，**原对象不能改**。
- `list` 可以原地增、删、改。
- `tuple` 单元素必须加逗号，否则 `(10)` 只是整数 `10`。

---

## 二、三者通用的操作（必须掌握）

`str`、`tuple`、`list` 都是序列，所以下面这些通用操作都支持：

| 通用操作        | 示例                          | 说明                                  |
| --------------- | ----------------------------- | ------------------------------------- |
| `len()`         | `len('abc')` → `3`            | 获取长度                              |
| 索引            | `s[0]`、`t[-1]`、`l[2]`       | 正索引从 `0` 开始，负索引从 `-1` 开始 |
| 切片            | `s[1:4]`、`t[::-1]`、`l[::2]` | 顾头不顾尾，步长可为负数              |
| `for` 遍历      | `for x in s:`                 | 逐个取出元素                          |
| `in` / `not in` | `'a' in s`                    | 判断元素是否存在，返回布尔值          |
| `index()`       | `s.index('a')`                | 查找位置，**找不到会报错**            |
| `count()`       | `l.count(1)`                  | 统计某个元素出现次数                  |
| `+` 拼接        | `'ab' + 'cd'`                 | 同类型拼接                            |
| `*` 重复        | `[1] * 3` → `[1, 1, 1]`       | 重复生成                              |

**记忆口诀：**

> **长度、索引、切片、遍历、in、index、count、+、* —— 三兄弟全都有。**

## 三、str 字符串特有方法

| 方法               | 作用                              | 记忆点                           |
| ------------------ | --------------------------------- | -------------------------------- |
| `find(x)`          | 查找子串位置，**找不到返回 `-1`** | `find` 温柔，找不到给 `-1`       |
| `index(x)`         | 查找子串位置，**找不到报错**      | `index` 暴躁，找不到就报错       |
| `replace(a, b, n)` | 替换内容，返回**新字符串**        | 不改原字符串                     |
| `split(sep)`       | 按分隔符切割，返回**列表**        | 字符串切成 `list`                |
| `join(seq)`        | 把序列拼接成字符串                | `'-'.join(['a', 'b'])` → `'a-b'` |
| `title()`          | 每个单词首字母大写                | 标题化                           |

**示例：**

```python
s = 'hello linux and hello linux'

# replace 返回新字符串，原字符串不变
new_s = s.replace('linux', 'python')
print(new_s)
print(s)

# split 返回列表
str2 = 'apple-banana-orange'
new_list = str2.split('-')
print(new_list)  # ['apple', 'banana', 'orange']

# join 把列表拼接成字符串
print('-'.join(new_list))  # apple-banana-orange

# title 每个单词首字母大写
print(str2.title())  # Apple-Banana-Orange
```
