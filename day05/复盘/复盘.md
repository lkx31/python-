字符串：是一个有序的可修改的不可变类型

字符串的定义：单双引号，三引号再给变量配值

索引从0开始的位置从1开始

len(list1)-1：这个是索引的最后一个值

索引的最大值=len(字符串)-1：7个字符，则下标索引最大值为7-1=6；从左向右读

`len()` 取的是**字符串的长度（也就是字符的个数）**，而**不是索引的最大值**

所谓切片：对操作的对象**截取**其中一部分的操作。字符串、列表、元组，range

包头不包尾巴

变量名[start:end : step]

**字符串是不可变类型（Immutable）**切片成功了，但它只是在内存里生成了一个**新的字符串 `'234'`**，然后就立刻被丢弃了

方法：内置方法和公用方法

注意：如果是不可变类型，就要用完方法要赋值给一个新的变量

内置方法：

查：index（），find（）

改：replace(要替换的内容，替换后的内容，次数)

​		split（‘要替换的内容’）:对字符串切割，返回一个列表类型

​		join：‘增加的内容’.join:列表中每一个元素的拼接符号, 将其拼接为一个字符串

```
asda="niubi--77"
asda1=asda.replace('77','11')
print(asda1)
asda2=asda1.split('-')
print(asda2)
asda3='-'.join(asda2)
print(asda3)
```

列表：定义[];list=[];是一个可以重复有序的可变类型

列表是一个可变类型可以直接操作不用重新赋值

查：index(要查的内容“)

​		count(计数的内容)

​		in和not in

增：append("要添加的内容")

​		extend（变量名）

​		inser(索引位置，添加内容”)

```
list1 = ['张三','李四','王五','赵六']
print(list1.index("张三"))
print(list1.count("张三"))
#append
list1.append("成长")
print(list1)
#extend
list2=["蛊真人","成长"]
list1.extend(list2)
print(list1)    

```

删除：del 列表[索引] :  删除指定索引的元素
       	 pop()  : 弹出元素  默认删除的列表尾部的元素, 并且会将删除的元素进行返回
       	 remove(元素):  用于删除指定的元素数据

```
list1 = ['老张', '张三', '老李', '李四', '王五', '赵六', '田七', '周八', '李九']
del list1[0]
print(list1)\
 #默认 弹出最后一个值，写的索引值
list1.pop()
print(list1)
list1.pop(1)
print(list1)
#remove
list1.remove("周八")
print(list1)

```
