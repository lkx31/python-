## 1. 面向对象编程（day01-02）

### 1.1 核心思想
- **面向过程**：自顶向下、逐步细化，把功能拆成按部就班的步骤（函数）。
- **面向对象 OOP**：模拟现实世界，先分析「哪个实体做什么动作」，把属性和功能封装到对象上，再让对象执行功能。万物皆对象。
- 面试题区别：① 都能复用代码，OOP 模块化更深、数据更封闭安全 ② OOP 更贴近现实、适合大型复杂业务 ③ 开发期 OOP 更复杂，但维护扩展更简单 ④ 执行效率面向过程更高。

### 1.2 类与对象
- **类**：具有相同属性和动作的一组实体的集合（模板，抽象，不占内存）。**对象**：通过类实例化出来的具体实体（占内存）。
- 定义类（类名大驼峰）：
```python
class Person(object):   # object 可不写，Python3 所有类默认继承 object
    def eat(self):
        print('吃零食')
```
- 实例化：`p1 = Person()`（Python 不需要 new 关键字）。
- **self**：指向调用该方法的实例对象本身，解释器自动传递，不用手动传。

### 1.3 属性
- 类外添加/获取：`对象名.属性 = 值` / `对象名.属性`；类内通过 `self.属性` 访问。
- 初始化赋值用 `__init__`。

### 1.4 魔术方法（记两点：触发条件 + 作用）
| 方法 | 触发时机 | 作用 |
| :--- | :--- | :--- |
| `__init__(self,...)` | 实例化对象时自动调用 | 初始化实例属性（构造是 `__new__`） |
| `__str__(self)` | print(对象) 时自动调用 | 必须 return 字符串（Java 的 toString） |
| `__del__(self)` | del 删除对象或程序结束时自动调用 | 析构：关闭文件、关闭数据库连接 |

### 1.5 封装（三大特性之一）
- 两层含义：① 把属性和方法写进类里 ② 加私有权限。
- **私有成员**：名字前加 `__`（如 `self.__age`、`def __card`），类外不能直接访问，**子类也不能继承**。
- 访问接口：`get_xx()` 获取、`set_xx()` 修改（内部可加类型/范围校验，过滤异常数据）。
- 私有方法意义：对外只暴露一个公共入口（如 ATM 的 withdraw），降低复杂度。

### 1.6 继承（三大特性之二）
- 语法：`class 子类(父类)`；**私有成员除外**，父类的公共属性和方法全部继承。
- 概念：派生=动作、继承=结果，二者一回事；父类=基类，子类=派生类；扩展=子类增加自己特有的成员。
- 单继承 / 多层继承（传递性）/ 多继承 `class A(B, C)`（尽量不用；同名冲突时继承顺序靠前的类优先）。
- **重写（覆盖）**：子类成员与父类同名时子类优先；父类方法还在，只是子类中找不到才会去父类找。
- **super()**：调用父类属性/方法。`super().__init__(brand, model, color)` 复用父类初始化；等价写法 `父类.方法(self)`。
- **MRO 方法解析顺序**：`类名.__mro__` 或 `类名.mro()` 查看；查找顺序：自身 → 父类 → … → object（object 是所有类的基类）。
- 易错：`__init__` 常被误写成 `__int__`。

### 1.7 多态（三大特性之三）
- 同一接口（方法）传入不同对象，产生不同结果。
- Python 是**伪多态**（鸭子理论：走路像鸭子、叫声像鸭子就是鸭子）——不强制继承、无类型声明，只要有同名方法就能统一调用。
- 例：`+` 号——数字相加 / 字符串拼接 / 列表合并。
- 好处：写出通用代码，适应需求变化。

### 1.8 类属性 / 类方法 / 静态方法（重点，必背对比表）
| 类型 | 定义位置 | 第一个参数 | 调用方式 | 能访问什么 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 实例属性 | `__init__` 或方法内 | — | `对象.属性` | 仅实例自己 | 每个对象独有的数据 |
| 实例方法 | 类内无装饰器 | self | `对象.方法()` | 实例属性+类属性 | 操作对象自身数据 |
| 类属性 | 类内、方法外 | — | `类名.属性` / `对象.属性` | 所有对象共享 | 共享数据、计数器 |
| 类方法 | @classmethod | cls | `类名.方法()` | 只能类属性 | 工厂方法、修改类属性 |
| 静态方法 | @staticmethod | 无默认参数 | `类名.方法()` | 都不能直接访问 | 挂靠在类里的普通函数、工具方法 |

### 1.9 综合案例模板
- 学生成绩等级（score 分段判断）、小明减肥（run 减 0.1 / eat 加 0.2）、烤地瓜（cook 累计时间→状态、add_condiments）、Game 类（top_score 类属性 + 静态/类/实例方法三合一）。

## 2. 闭包与装饰器（day03）

### 2.1 作用域与变量
- 全局变量：全局定义；局部变量：函数内定义。
- 局部作用域能读全局变量；全局不能读局部变量（函数执行完，内部变量被垃圾回收机制 gc 回收）。

### 2.2 闭包（三步走）
- 条件：① 有嵌套 ② 内部函数**引用**外部函数的变量 ③ 外部函数**返回**内部函数。
- 作用：函数结束后仍可间接访问其局部变量（延迟销毁）；代价：变量不释放，消耗内存。
- 在内部函数里**修改**外层局部变量用 `nonlocal`；修改全局变量用 `global`。
```python
def func():
    result = 0
    def inner(num):
        nonlocal result
        result += num
        print(result)
    return inner
f = func()
f(1)  # 1
f(2)  # 3  —— result 没有消失，一直在累加
```

### 2.3 装饰器
- 目的：**不修改源代码、不修改调用方式**的前提下增强函数功能（登录验证、日志、计时）。
- 本质：闭包。语法糖 `@装饰器名` 等价于 `函数 = 装饰器(函数)`。
- **通用模板（背下来）**：
```python
def outer(fn):                       # fn：被增强的函数
    def inner(*args, **kwargs):      # ①嵌套 ②引用(fn)
        # ---- 增强代码（前）----
        result = fn(*args, **kwargs) # 接收原函数返回值
        # ---- 增强代码（后）----
        return result                # 原函数有返回值必须 return
    return inner                     # ③返回
```
- 带参数的装饰器：外面再套一层函数接收参数（三层嵌套）。
- 嵌套装饰器：**由下往上装饰，由上往下运行**。
- 企业用法：装饰器单独放一个模块文件（如 MyDecorator.py），`import 模块 as m` 后 `@m.log` 使用。

### 2.4 案例
- 登录+验证码双重装饰、既能装饰加法又能装饰减法的装饰器、统计函数被调用次数、正整数计算器。

## 3. 网络编程（day04）

### 3.1 网络三要素
- **IP**：找设备（IPv4 目前 / IPv6 未来）；**端口**：找设备上的程序（数据传输的通道）；**协议**：规范客户端和服务器之间如何传输数据。
- 域名 = IP 的别名；http 默认 80（不加密），https 默认 443（加密）。
- 端口分类：知名 0-1023（FTP 21、SSH 22、SMTP 25、HTTP 80、HTTPS 443）；注册 1024-49151（MySQL 3306、Redis 6379、Ollama 11434）；动态 49152-65535（系统自动分配）。开发建议 8000 以后。

### 3.2 HTTP 协议
- 请求：请求行（方式 GET 查询 / POST 新增 / PUT 修改 / DELETE 删除 + 请求路径）→ 请求头（浏览器本地信息）→ 请求体（真实需要传输的数据）。
- 响应：响应行（状态码 1xx-5xx：200 成功 / 304 本地有缓存 / 404 资源找不到 / 500 服务器代码报错）→ 响应头 → 响应体（网页真正展示的内容）。
- 代码访问：`import requests; responses = requests.get(url); responses.content.decode()`。

### 3.3 TCP / UDP
- TCP 传输控制协议：面向连接、可靠、基于字节流。步骤：建立连接 → 传输数据 → 关闭连接（像打电话）。
- 可靠机制：发送应答、超时重传、错误校验、流量控制；连接基于三次握手、四次挥手。
- UDP：不可靠但快（如视频通话）——能保证速度，不保证数据质量。

### 3.4 编码转换
- 网络中数据是二进制：发送 `str.encode('utf-8')` → bytes；接收 `bytes.decode('utf-8')` → str。

### 3.5 socket 编程
- socket 套接字：程序间网络通信的约定/工具。
- **TCP 客户端五步**：创建 `socket.socket(AF_INET, SOCK_STREAM)` → `connect((ip, 端口))`（参数必须是元组）→ `send(data.encode())` → `recv(1024).decode()` → `close()`。
- **TCP 服务端七步**：创建 → `bind(("", 端口))` → `listen(128)` → `accept()`（阻塞，返回 `(新套接字, 客户端ip端口)`）→ `recv` → `send` → `close`。
- 端口复用：`setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, True)`（重启服务不报端口占用）。
- 扩展：多轮对话（while True 内 recv，收到空数据表示客户端已关闭）；飞秋消息（UDP 2425 端口，gbk 编码，群发需 `SO_BROADCAST` 广播）。

## 4. 多任务编程（day05）

### 4.1 并发 vs 并行
- 并发：一段时间内交替执行多个任务（单核 CPU 轮转，看起来同时）。
- 并行：真正同时执行多个任务（多核 CPU）。

### 4.2 多进程 multiprocessing
- 进程：资源分配的最小单位；一个运行的程序至少一个进程。
```python
import multiprocessing
p = multiprocessing.Process(target=任务函数, args=(3,), kwargs={'count': 3})
p.start()
```
- 传参：args 元组（单参数也要逗号 `(3,)`）、kwargs 字典（键必须与函数形参名一致）。
- 进程编号：`os.getpid()` 当前进程、`os.getppid()` 父进程；`multiprocessing.current_process().name` 进程名。
- **进程间不共享全局变量**：创建子进程 = 拷贝主进程资源，各操作各的副本。
- 主进程默认等子进程结束；两种方式让子进程随主进程销毁：① 守护进程 `p.daemon = True` ② 手动 `p.terminate()`。
- 其他：`p.kill()` 杀死、`p.join()` 等待进程结束、`p.is_alive()` 判断是否运行。
- 进程优缺点：能用多核；资源开销大。

### 4.3 多线程 threading
- 线程：程序执行的最小单位；进程是线程的容器，一个进程至少一个线程；同一进程的线程共享该进程的全部资源。
```python
import threading
t = threading.Thread(target=任务, args=(3,), daemon=True)
t.start()
```
- **线程间共享全局变量**（和进程相反）；线程执行顺序无序（由 CPU 调度决定）。
- 守护线程：`Thread(..., daemon=True)` 或 `t.setDaemon(True)`（后者有警告）。
- **互斥锁**（多线程操作共享数据时防止竞态）：
```python
lock = threading.Lock()
lock.acquire()   # 获取锁（被占用则阻塞等待）
# ...操作共享数据...
lock.release()   # 释放锁
lock.locked()    # 检查是否被占用
```

### 4.4 进程 vs 线程（必背）
| 对比 | 进程 | 线程 |
| :--- | :--- | :--- |
| 关系 | 线程依附于进程 | 一个进程默认至少一条线程 |
| 全局变量 | 不共享 | 共享 |
| 开销 | 大 | 小 |
| 单位 | 资源分配的基本单位 | CPU 调度的基本单位 |
| 多核 | 可用 | 不可用（GIL 限制） |

### 4.5 生成器与协程
- 生成器：按规则用一次生成一个，节省内存。创建：① 生成器推导式 `(i*2 for i in range(5))` ② 函数中用 `yield`。
- 取值：`next(生成器)` 或 for 遍历；执行到 yield 暂停返回，下次从暂停处继续；取完再取抛 StopIteration（for 自动处理，while 需手动捕获）。
- **yield vs return**：return 返回后函数终止、局部变量销毁；yield 返回生成器对象，可反复迭代、状态保留。
- **协程**（从生成器发展而来，I/O 等待时不闲着）：
  - 三要素：① 函数前加 `async` ② 等待处加 `await` ③ 启动用 `asyncio.run`。
  - 三步骤：定义 async 函数 → `asyncio.create_task(协程())` 创建任务 → `await` 等待结果。
- **协程 vs 线程 vs 进程**：协程=单线程内切换（数量上万、内存几 KB、I/O 密集最佳）；线程=看起来同时（GIL）；进程=真正同时（计算密集）。
- 选择指南：网络请求/文件读写 → 协程；数学计算 → 多进程；简单后台任务 → 多线程。

## 5. 正则表达式（day06）

### 5.1 三大匹配方式（re 模块）
| 方法 | 规则 | 成功 | 失败 |
| :--- | :--- | :--- | :--- |
| `re.match(正则, 字符串)` | 只能从**开头**匹配，只返回第一个 | match 对象，需 `.group()` 提取 | None |
| `re.search(正则, 字符串)` | 全串搜索，只返回第一个 | match 对象 | None |
| `re.findall(正则, 字符串)` | 全串搜索，返回**所有** | 列表 | 空列表 [] |

- 注意：findall 的**正则里有分组时，列表中只放分组内容**。
- 三大步：导包 `import re` → 匹配 → 处理数据。

### 5.2 匹配规则
- 单字符（记忆：d=digit 数字、s=space 空白、w=word 词）：`.` 任意1个（除 \n）、`[]` 括号内任意1个（或关系）、`\d` 数字、`\D` 非数字、`\s` 空白（空格 \t \n）、`\S` 非空白、`\w` 字母数字下划线汉字、`\W` 特殊字符。
- 多字符（量词，修饰**前一个**字符）：`*` ≥0 次、`+` ≥1 次、`?` 0或1 次、`{x}` 恰好 x 次、`{x,y}` x到y 次。
- 开头结尾：`^` 以…开头、`$` 以…结尾，配合使用做**精确限制**（如密码位数校验）。
- 分组：`|` 或；`()` 分组（从 1 编号，`group(n)` 取第 n 组，`group(0)` 取全部）；`\n` 反向引用第 n 组；`(?P<name>)` 命名、`(?P=name)` 按名引用。
- 特殊：`^` 放 `[]` **里面**表示取反（`[^\d]` == `\D`）；匹配有特殊含义的字符要转义（如邮箱里的 `\.`）。

### 5.3 贪婪与非贪婪
- `*` `+` 默认**贪婪**（匹配成功前提下尽可能多）；量词后加 `?` 变**非贪婪**（尽可能少）：`.*?`、`.+?`。

### 5.4 修饰符
- `re.I` 不区分大小写；`re.S` 让 `.` 也能匹配 \n。

### 5.5 常用正则
- 微博话题 `#.+#`；11 位手机号 `^1[0-9]{10}$`；邮箱 `^[a-zA-Z0-9_]{4,20}@163\.com$`。

## 6. 数据库（day07-08）

### 6.1 基础概念
- 数据库 = 数据库本身（仓库）+ DBMS（管理系统，如 MySQL/Oracle）。用户通过 DBMS 访问数据。
- **关系型 SQL**：二维表、行/列、主键外键、SQL 声明式语言、ACID 强一致（MySQL/Oracle/PostgreSQL/SQLite）→ 适合银行、电商等一致性命脉的业务。
- **非关系型 NoSQL**：无固定表结构、灵活、可扩展、读写快（键值 Redis / 文档 MongoDB / 列族 HBase / 图 Neo4j）→ 适合海量数据、日志、社交动态。
- SQL 分类：DDL 定义（create/drop/alter）、DML 操作（insert/delete/update）、DQL 查询（select）、DCL 控制（权限）、TCL 事务。

### 6.2 连接与库表操作
- 连接：`mysql -u用户名 -p密码`（-h 主机）；退出 exit / quit / \q。
- 库：`create database [if not exists] 库名 [charset utf8];`、`use 库名;`、`show databases;`、`drop database 库名;`
- 数据类型：varchar(长度) 变长 / char(长度) 定长（不足补空格）；int（默认 11，不够用 bigint）；float / double / decimal(总长度, 小数位)；date / datetime / year。
- 约束：primary key（唯一+非空）、auto_increment（自增，配合主键）、not null、unique、default、foreign key（限制从表插入、主表删除）。
- 表：`create table 表(字段 类型 [约束], ...);`、`show tables;`、`desc 表;`、`drop table [if exists] 表;`、`rename table 旧 to 新;`、`alter table 表 add|drop 字段...` / `change 旧名 新名 类型`（改名+改类型）/ `modify 字段 类型`（只改类型）。

### 6.3 DML 增删改
- 增：`insert into 表 (字段...) values (值...), (值...);`（值与字段一一对应；插入所有字段时可省略字段名）。
- 改：`update 表 set 字段=值 [where 条件];`（**不加 where 改全部，慎用**）。
- 删：`delete from 表 [where 条件];`（自增顺序保留）vs `truncate [table] 表;`（清空且自增重置）。

### 6.4 单表查询（重点）
- 基础：`select [distinct] 字段|* from 表 [as 别名];` —— distinct 去重、as 起别名（给表起别名后必须用别名调用字段）。
- 条件 where：比较 `> < >= <= != <>`；逻辑 `and or not`；范围 `between x and y`（连续）、`in(值,...)`（非连续）；模糊 `like`（`%` 任意多个字符、`_` 任意 1 个字符）；判空 `is null` / `is not null`（**不能用 = null**；注意区分 null、''、'null' 字符串）。
- 排序：`order by 字段 [asc|desc], 字段2 ...`（asc 默认升序；多字段先按前面排，值相同再看后面）。
- 聚合函数：`sum() count() avg() max() min()`；聚合函数(字段)会忽略 null，统计个数用 `count(*)`（不忽略 null）。
- 分组：`select 分组字段, 聚合函数(字段) from 表 [where 非聚合条件] group by 分组字段 [having 聚合条件];` —— select 后的字段要么出现在 group by 后，要么在聚合函数中（否则报 only_full_group_by）。
- **where vs having**：位置（group by 前/后）；执行（分组前/后）；where 后不能跟聚合条件、having 可以；having 可以用别名、where 不行。
- 分页：`limit 起始索引, 条数;` 起始 = (页数-1)*条数；可做 topN（并列问题需开窗函数）。
- **书写顺序 vs 执行顺序**（面试常考）：
  - 书写：SELECT → DISTINCT → 聚合 → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT
  - 执行：FROM → WHERE → GROUP BY → 聚合 → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT

### 6.5 多表查询
- 多表关系：一对一、一对多、多对多（借中间表拆成两个一对多）。
- 外键：从表（多方）字段引用主表（一方）主键；类型必须与主表主键一致。
- 交叉连接 `cross join`（笛卡尔积 = 两表记录数乘积，本质是错误，慎用）。
- 内连接 `inner join ... on 关联条件`（两表交集；隐式写法 `from 左表,右表 where 关联条件`）——常用。
- 外连接：`left outer join`（以左表为主，保留左表全部）/ `right outer join`（保留右表全部）。
- 全外连接：MySQL 没有 full outer join，用左外 + `union`（去重）/ `union all`（不去重）+ 右外模拟。
- 自连接：同一张表 join 自己（如省市县 areas 表），**必须起别名**。
- 子查询：select 里嵌 select，辅助主查询（如 `where pid = (select id from areas where title='河北省')`）。

### 6.6 PyMySQL（Python 操作 MySQL）
- 安装：`pip install pymysql`（慢可用清华源 `-i https://pypi.tuna.tsinghua.edu.cn/simple/`）。
- 六步：导包 → `pymysql.connect(host, port, user, password, database)` → `conn.cursor()` → `cur.execute(sql)`（返回影响行数）→ `cur.close()` → `conn.close()`。
- 查询取数据：`fetchone()` 一条 / `fetchall()` 剩下的全部。
- **增删改**：InnoDB 引擎必须 `conn.commit()` 提交，出错时 `conn.rollback()` 回滚；MyISAM 不支持事务，不 commit 也生效。事务特性：原子性、一致性、隔离性、持久性。
- **SQL 注入**：字符串拼接传参会出事（密码输入 `' or 1=1 --` 恒真）。解决：SQL 用 `%s` 占位，参数放列表单独传给 execute：
```python
sql = "select * from user where user=%s and pwd=%s"
row = cur.execute(sql, [username, password])
```

### 6.7 Redis（非关系型）
- 基于内存的键值对数据库，可用作数据库、缓存、消息中间件；持久化（RDB 快照 / AOF 日志）；5 种数据类型；操作原子。
- 应用：缓存、计数器、消息队列（List）、排行榜（ZSet）、会话存储。
- 验证：`redis-cli` → `ping` 返回 PONG。默认端口 6379。
- Python：`pip install redis` → `import redis`；连接 `r = redis.Redis(host='localhost', port=6379, db=0, decode_responses=True, protocol=2)`。
- 常用命令速查：
| 类型 | 常用命令 |
| :--- | :--- |
| String | set / get / mset / mget / setex(键,秒,值) / incr / incrby / decr / decrby |
| Hash | hset / hget / hgetall / hmset / hmget / hkeys / hvals / hdel |
| List | lpush / rpush / llen / lrange(键,0,-1) / lpop / rpop |
| Set | sadd / smembers / sismember / scard / spop / srem / sinter(交) / sunion(并) / sdiff(差) |
| ZSet | zadd / zrange(升序) / zrevrange(降序) / zscore / zincrby / zrevrank / zrangebyscore，带分数加 withscores=True |
| 键操作 | exists / expire(秒) / ttl / setex / persist(取消过期) / keys(模式) / delete |

## 7. 数据分析三剑客（day09）

- 层次：**NumPy 基础层**（数值计算）→ **Pandas 数据处理层**（基于 NumPy）→ **Matplotlib 可视化层**。
- 导入惯例：`import numpy as np` / `import pandas as pd` / `import matplotlib.pyplot as plt`。

### 7.1 NumPy
- 创建数组：`np.array(列表)`、`np.zeros((3,4))` 全0 / `np.ones((2,3))` 全1（**参数是形状元组**）、`np.arange(起,止,步长)`、`np.linspace(起,止,份数)`、`np.random.rand(3,3)` [0,1) 均匀 / `randn` 标准正态。
- 属性：`ndim` 维度、`shape` 形状、`size` 元素总数、`dtype` 类型。
- 索引切片：`arr[行,列]`；`arr[:,1]` 所有行的第2列；布尔索引 `arr[arr>5]`；切片是视图（改切片影响原数组）。
- 形状：`reshape(3,4)` 重塑（元素总数不变）、`.T` 转置、`flatten()` 展平、`np.resize`。
- 运算：`+ - * /` 元素级；比较返回布尔数组；**矩阵乘法 `np.dot(a, b)`**（(m,n)·(n,k)→(m,k)，不满足交换律，区别于元素级 `*`）。
- 统计：`sum/mean/std/var/min/max/argmin/argmax`；**axis=0 沿列方向（求每列），axis=1 沿行方向（求每行）**。
- 广播：不同形状数组运算时自动扩展（规则：从最后一维对齐，相等或其一为 1）。

### 7.2 Pandas
- **Series**：一维带标签数组；**DataFrame**：二维表格。
- 创建 DataFrame：① 列表（行角度，需 `columns=` 指定列名）② 字典（列角度，key 即列名）③ `pd.read_csv(文件, sep=',', names=[...])`。
- 查看：`head(n)/tail(n)` 前后几行、`describe()` 描述性统计、`info()`、`shape/columns/index/dtypes`。
- 选择：`df['列']` 单列、`df[['列1','列2']]` 多列；**`loc` 按标签索引（切片左闭右闭）、`iloc` 按位置索引（切片左闭右开）**；行列同时取 `df.loc[行, 列]`。
- 筛选：`df[df['年龄']>30]`；`df.query('年龄 > 28 and 工资 < 7000')`；排序 `df.sort_values('工资', ascending=False)`（多列排序传列表）。
- 缺失值：`isnull().sum()` 统计；`dropna()` 删含缺失的行（`how='all'` 全空才删）；`fillna(0/均值)` 填充；`ffill` 前向填充 / `bfill` 后向填充。
- 分组聚合：`df.groupby('产品')['销售额'].sum()`；`agg(['sum','mean'])` 多统计量；透视表 `pivot_table(index='产品', values='销售额', aggfunc='sum')`。

### 7.3 Matplotlib
- 固定配置：`matplotlib.use('TkAgg')` 指定后端；中文显示：`plt.rcParams['font.sans-serif'] = ['SimHei']`、`plt.rcParams['axes.unicode_minus'] = False`。
- 流程：`plt.figure(figsize=(8,5))` → `plt.plot(x,y,color=,label=)` 折线 / `plt.scatter` 散点 → `title/xlabel/ylabel` → `legend()` 图例 → `grid()` 网格 → `show()`。

### 7.4 综合案例（GDP 分析套路）
读 csv → `dropna` 清洗 → 条件筛选取三国数据 → `set_index('year')` → `rename` 改列名 → 三条 plot 画折线 → legend/grid/show。

## 8. Linux 系统（day10）

### 8.1 环境
- 计算机 = 硬件（冯·诺依曼：输入/输出/运算器/控制器/存储器）+ 软件（系统软件 + 应用软件）；操作系统是硬件与应用之间的桥梁。
- Linux 1991 年由林纳斯·托瓦兹创建；发行版：CentOS/RedHat/Ubuntu 等（课程用 CentOS 7）。
- VMware 虚拟网卡模式：**NAT（推荐，借 Windows 上网）/ 桥接（借路由器上网）/ 仅主机（不能上网）**；安装后要检查 net1、net8 虚拟网卡。
- 快照：关机状态下拍摄，用于回滚；FinalShell 客户端连接虚拟机（ssh 工具）。

### 8.2 目录结构
- 树型结构，**只有一个根目录 `/`**（Windows 有多个盘符）。
- 常见目录：/bin 常用命令、/etc 配置文件、/home 普通用户家目录、/root root 家目录、/usr 应用程序、/tmp 临时文件、/opt 额外软件、/proc 内核与进程信息。

### 8.3 常用命令
- 命令格式：`command [-options] [parameter]`。
- 四大基础：`ls`（-a 隐藏 / -l 详细（=ll）/ -h 人性化大小）、`cd`（~ 家目录，可省略）、`pwd`、`clear`（ctrl+L）。
- 路径：绝对（以 / 开头）vs 相对（`./` 当前可省略、`../` 上级）。
- 帮助：`命令 --help`、`man 命令`。
- 文件目录：`mkdir -p 多层目录`；`touch 文件`；`cat -n 文件`（小文件）；`more/less`（空格下页、q 退出）；`head/tail -n 文件`（默认 10 行，`tail -f` 实时跟踪日志）。
- 复制移动删除：`cp -r 源 目标`（复制，源保留；-r 复制文件夹）；`mv 源 目标`（移动/剪切；**目标目录不存在会被当成改名**）；`rm -rf`（强制删除，慎用）。
- 输出重定向：`echo 内容` 打印；`>` 覆盖写入、`>>` 追加写入（`echo 'hello' >> h.txt`）。
- 打包压缩：`tar -cvf 包.tar 文件...` 打包 / `tar -xvf 包.tar -C 目标` 解包；gzip 加 z：`tar -zcvf` / `tar -zxvf`（**-f 必须在所有选项最后**）。
- 进程网络：`find 路径 -name 文件名`；`ps -ef | grep 关键字`；`ping`（`&` 放后台运行）；`kill -9 pid` 强杀。

### 8.4 vi / vim 编辑器
- vi = 记事本，vim = notepad++（功能更强）。`vim 文件名`（不存在自动创建）。
- 三种模式：命令模式（默认）→ 按 `i` 进入插入模式（编辑）→ 按 `ESC` 回命令模式 → 按 `:` 进入底线命令模式。
- 保存退出：`:w` 保存、`:q` 退出、`:q!` 强制退出、`:wq` 保存并退出、`:wq!` 强制保存退出。
- 典型应用：`vim /etc/sysconfig/network-scripts/ifcfg-ens33` 改固定 IP（BOOTPROTO=static + IPADDR/NETMASK/GATEWAY/DNS），改完 `systemctl restart network`，`ifconfig` 查看 IP。

### 8.5 权限（扩展）
- `ll` 输出的权限位：第 1 位类型（d 目录 / - 文件 / l 链接），后 9 位每 3 位一组：属主 user / 属组 group / 其他 other，每组 r（读）w（写）x（执行）。
- chmod 三种写法：`chmod u+rwx 文件`（字母加减）、`chmod u=rwx 文件`（赋值）、`chmod 777 文件`（数字法：r=4、w=2、x=1，如 652 = rw-r-x-w-）。
