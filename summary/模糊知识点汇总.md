# 模糊知识点汇总

> 记录掌握不牢固、容易混淆或经常遗忘的知识点，作为重点复习清单。
> 来源：10 天课件中标注「注意/易错」的地方和各类对比表（不一定是你的个人模糊点，请按自己情况筛选使用）。
> 用法：复习确认掌握后把 `- [ ]` 改成 `- [x]`；整节都掌握的可以直接删掉该节。

---

## 一、面向对象（day01-02）
- [ ] **面向过程 vs 面向对象**（面试题）—— 按步骤写函数 vs 先找主体再封装功能
- [ ] **类 vs 对象** —— 类=抽象模板不占内存；对象=具体实例占内存
- [ ] **`__init__` vs `__new__` vs `__int__`** —— init 是初始化（自动调用）；new 是构造；`__int__` 是手误错写
- [ ] **`__str__` 必须 return 字符串** —— 否则 print(对象) 会出问题
- [ ] **私有成员 `__` 前缀** —— 类外不能直接访问、子类不能继承，需要 get/set 接口
- [ ] **继承 vs 派生** —— 派生是动作、继承是结果，同一件事两个角度
- [ ] **重写 vs 重载** —— Python 没有重载；重写=子类覆盖父类同名成员，父类方法还在
- [ ] **super() 两种写法** —— `super().__init__(...)`（推荐） / `父类.__init__(self, ...)`
- [ ] **MRO 查找顺序** —— 自身类 → 父类 → … → object，可用 `类名.__mro__` 查看
- [ ] **多继承同名冲突** —— 继承顺序靠前的类优先；开发中尽量避免多继承
- [ ] **多态 / 鸭子理论** —— Python 伪多态：不强制继承，有同名方法就能统一调用
- [ ] **类属性 vs 实例属性** —— 类属性所有对象共享（`类名.属性`）；实例属性各对象独有（`self.属性`）
- [ ] **类方法 vs 静态方法** —— 类方法有 cls 能访问类属性；静态方法无默认参数，只是挂靠在类里的普通函数

## 二、闭包与装饰器（day03）
- [ ] **global vs nonlocal** —— global 引用全局变量；nonlocal 修改外层函数的局部变量
- [ ] **闭包 vs 装饰器** —— 装饰器本质就是闭包（嵌套+引用+返回）
- [ ] **嵌套装饰器顺序** —— 由下往上装饰，由上往下运行
- [ ] **带返回值装饰器** —— inner 里必须 `return fn(*args, **kwargs)`，否则原函数返回值丢失（变 None）
- [ ] **带参数装饰器** —— 三层嵌套：接收参数 → 接收函数 → inner
- [ ] **通用装饰器模板** —— 背下来（见汇总「2.3 装饰器」）

## 三、网络编程（day04）
- [ ] **TCP vs UDP** —— TCP 可靠（应答/重传/校验/流量控制，三次握手四次挥手）但慢；UDP 快不可靠（视频通话）
- [ ] **encode vs decode 方向** —— 发送：字符串 encode → 二进制；接收：二进制 decode → 字符串
- [ ] **端口三段** —— 知名 0-1023（HTTP 80 / HTTPS 443 / SSH 22 / FTP 21）；注册 1024-49151（MySQL 3306 / Redis 6379）；动态 49152-65535
- [ ] **状态码含义** —— 200 成功 / 304 缓存 / 404 找不到 / 500 服务器报错；1xx-5xx
- [ ] **TCP 客户端五步 vs 服务端七步** —— 服务端多 bind 和 listen；accept() 阻塞并返回 (新套接字, 客户端地址)

## 四、多任务（day05）
- [ ] **并发 vs 并行** —— 单核交替执行 vs 多核真正同时执行
- [ ] **进程 vs 线程** —— 进程=资源分配单位、不共享全局变量、开销大、能用多核；线程=CPU 调度单位、共享全局变量、开销小、GIL 限制不能用多核
- [ ] **GIL** —— 全局解释器锁：同一时刻只有一个线程执行 Python 字节码，所以多线程不能加速 CPU 密集型任务
- [ ] **守护进程 daemon vs terminate()** —— 两种都能让主进程退出时子进程销毁：守护是设属性，terminate 是主动杀死
- [ ] **args 单参数要写逗号** —— `args=(3,)` 才是元组，`(3)` 只是普通括号
- [ ] **yield vs return** —— return 函数终止、变量销毁；yield 暂停、下次从暂停处继续、返回生成器
- [ ] **生成器取完再取** —— 抛 StopIteration（for 自动处理，while 需手动 try）
- [ ] **协程三要素** —— async 定义 / await 等待 / asyncio.run 启动；I/O 密集首选协程

## 五、正则表达式（day06）
- [ ] **match vs search vs findall** —— 开头第一个 / 全串第一个 / 全串所有（返回列表）
- [ ] **findall + 分组** —— 有分组时列表里只放分组内容
- [ ] **贪婪 vs 非贪婪** —— `.*` 尽可能多 vs `.*?` 尽可能少（量词后加 ?）
- [ ] **`^` 的位置** —— 在表达式开头=行首；在 `[]` 里面=取反（`[^\d]` == `\D`）
- [ ] **`.` 要转义** —— 匹配真正的点要写 `\.`（如邮箱 `@163\.com`）
- [ ] **`\w` 范围** —— 字母、数字、下划线、汉字

## 六、MySQL（day07）
- [ ] **varchar vs char** —— 变长按实际占位 vs 定长不足补空格
- [ ] **delete vs truncate** —— delete 保留自增顺序；truncate 清空并重置自增
- [ ] **null vs '' vs 'null'** —— SQL 判空只能 `is null`，`= null` 查不到
- [ ] **count(*) vs count(字段)** —— count(字段) 忽略 null；统计个数用 count(*)
- [ ] **where vs having** —— where 分组前过滤（不能用聚合函数）；having 分组后过滤（能用聚合函数和别名）
- [ ] **group by 规则** —— select 后的字段要么在 group by 里，要么在聚合函数里，否则报 only_full_group_by
- [ ] **union vs union all** —— 去重 vs 不去重；MySQL 全外连接用 union 模拟
- [ ] **交叉连接 vs 内连接 vs 外连接** —— 笛卡尔积（错误） / 交集 / 保留一边的全部
- [ ] **SQL 书写顺序 vs 执行顺序** —— 执行从 FROM 开始（面试常考）
- [ ] **自连接必须起别名** —— 同一张表自己 join 自己

## 七、PyMySQL 与 Redis（day08）
- [ ] **InnoDB vs MyISAM** —— InnoDB 支持事务（增删改必须 commit/rollback）；MyISAM 不支持
- [ ] **SQL 注入** —— 别用 f-string 拼 SQL；用 `%s` 占位 + 参数列表
- [ ] **RDB vs AOF** —— RDB 快照机制 / AOF 日志机制（Redis 两种持久化）
- [ ] **Redis 5 种类型用途** —— String 缓存计数 / Hash 对象字段 / List 消息队列 / Set 去重集合 / ZSet 排行榜
- [ ] **setex 参数顺序** —— `setex(key, 秒, value)`

## 八、数据分析（day09）
- [ ] **axis=0 vs axis=1** —— axis=0 沿列方向（汇总每列）；axis=1 沿行方向（汇总每行）
- [ ] **np.dot vs `*`** —— 矩阵乘法（形状要匹配、不满足交换律）vs 元素级乘法
- [ ] **广播规则** —— 从最后一维对齐，相等或其一为 1 才能广播
- [ ] **loc vs iloc** —— 标签索引（切片左闭右闭）vs 位置索引（切片左闭右开）
- [ ] **Series vs DataFrame** —— 一维带标签数组 vs 二维表格
- [ ] **dropna vs fillna** —— 删除缺失 vs 填充缺失（ffill 前向 / bfill 后向）

## 九、Linux（day10）
- [ ] **绝对路径 vs 相对路径** —— / 开头 vs 从当前目录出发（`./`、`../`）
- [ ] **mv 到不存在的目录** —— 会被当成重命名，不会报错
- [ ] **chmod 数字法** —— r=4 w=2 x=1；三组分别是属主/属组/其他
- [ ] **vi 三种模式** —— i 进入插入模式；ESC 回命令模式；:wq 保存退出
- [ ] **tar -f 必须在最后** —— `tar -zxvf 包.tar.gz -C 目标`
- [ ] **NAT vs 桥接 vs 仅主机** —— 借 Windows 上网 / 借路由器上网 / 不能上网
