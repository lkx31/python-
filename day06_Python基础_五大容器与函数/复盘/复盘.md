## 二、今日核心知识点总结

### 1. 集合 set【熟悉】
- **三大特性**：无序、去重（天生去重）、可变
- **定义**：有数据 `{1, 2, 3}`；**空集合只能用 `set()`**（`{}` 是空字典！）
- **增** `set.add(元素)`；**删** `set.remove(元素)`（不存在会报错）、`set.pop()`（随机弹出并返回）；**查** `in` / `not in`；**遍历** `for i in set1`
- 案例：缺失数字求和 —— 用 `max()`/`min()`（或遍历）找两端，`range(min, max)` 遍历找不在集合中的数并累加

### 2. 字典 dict【掌握】
- **概念**：`{key: value}` 键值对，**key 唯一**（类似索引下标），逗号隔开；value 可重复
- **定义**：`dict1 = {'name': 'Tom', 'age': 20}`；空字典 `{}` 或 `dict()`；key 要加引号（一般是字符串）
- **增改**（同一个语法）：`字典[key] = value` —— key 存在则改，不存在则增
- **删**：`del 字典[key]`（删指定键值对）、`字典.clear()`（清空）
- **查**：`字典[key]`（不存在直接报错）、`keys()` 所有键、`values()` 所有值、`items()` 所有键值对（元组形式）
- **遍历**：`for k in person.keys(): v = person[k]` 或 `for k, v in person.items()`
- 案例：字符出现次数统计（`在字典中则 +1，不在则初始化为 1`）；字符串转字典（`split(' ')` 再 `split('=')` + 拆包）

### 3. 容器拆包【实操】
- 定义：把容器中的数据一个个拆出来，赋值给多个变量
- 语法：`num1, num2 = (10, 20)` → 可简写 `num1, num2 = 10, 20`；**变量个数必须与元素个数一致**
- 经典应用①：交换变量 `c1, c2 = c2, c1`（不需要第三方变量）
- 经典应用②：接收函数多返回值 `o_sum, j_sum = calculate_sum(nums)`

### 4. 推导式【扩展】
- 适用场景：遍历一个容器 → 生成一个新容器（从旧到新，逻辑别太复杂）
- **列表推导式**：`[表达式 for i in 序列]`、`[表达式 for i in 序列 if 条件]`、`[表达式 for i in 序列 for j in 序列]`（嵌套）
- **执行顺序**：先执行右边 for 循环，每轮结果放进最左边表达式，追加到新容器
- **集合推导式**：`{i**2 for i in range(1, n+1)}` —— 外层是 `{}`，结果去重

### 5. 函数基础【实操】
- **为什么**：① 代码重用 ② 模块化编程（一个功能一个函数，功能要专一）
- **定义与调用**：`def 函数名([参数]): 函数体 [return 返回值]`；`[]` 表示可选；**函数不调用不执行、先定义后使用**
- **return 三思考**：
  1. 两个 return → 只执行第一个，return 会**退出函数**，后面代码不执行
  2. 多返回值 `return 1, 2` → 实际返回**元组** `<class 'tuple'>`
  3. 四则运算返回 4 个值 → `return jia, jian, cheng, chu`，打印出来是元组
- 卖票案例三阶段：无参函数 → 带参函数 → 带返回值函数

### 6. 函数嵌套调用【知道】
- 一个函数里调用另一个函数
- 执行流程：**定义时只声明不执行**（跳过函数体）→ 调用时跳入执行 → 内层函数执行完返回调用处继续

### 7. 应用案例：奇偶求和【实操】
- 函数 `calculate_sum(nums_list)` 分别累加奇数和偶数，`return o_sum, j_sum`（元组）
- 调用处用**拆包接收**：`o_sum, j_sum = calculate_sum(numbers_list)`

### 8. 变量作用域【知道】
- 区分：**定义在函数内部 = 局部作用域**（局部变量），**def 外面 = 全局作用域**（全局变量）
- 规则：全局变量在函数内**可以读**；局部变量函数执行完**销毁**（垃圾回收），函数外不能用
- 关键结论：函数内 `num = 20` **不是修改全局变量，而是新建了一个局部变量** —— 要改全局必须：
  ```python
  def func():
      global num   # 声明要改的是全局变量
      num = 20
  ```
- **global 只针对不可变类型**（number/str/bool/tuple）；可变类型（list/set/dict）在函数里改**内容**（如 `list.append()`）不需要 global —— 课件特别标注，涉及后续理解

### 扩展：可变 / 不可变类型
- 判断标准：能否**原地修改**，用 `id(变量)` 看内存地址是否变化
- **不可变**：str、number、bool、tuple —— "修改"实际上是创建新对象
- **可变**：list、set、dict —— 原地修改，id 不变

### 七大基本类型小结（背）
```
数字 number    : int float           不加引号
布尔 bool      : True False          不加引号
字符串 str     : ' " ''' 三引号      序列、索引切片、有序、可重复、不可修改
列表 list      : [元素, 元素]        序列、索引切片、有序、可重复、可修改
元组 tuple     : (元素, 元素)        序列、索引切片、有序、可重复、不可修改
集合 set       : {元素, 元素}        无序、不重复、可变
字典 dict      : {key:value, ...}    键值对格式、key 唯一
```

- ❌ **"集合……是一个有序" —— 写反了！** 课件 1.1 原文：集合是**无序**的不重复元素序列。有序的是 str/list/tuple（序列类型），集合不能索引、每次打印顺序都可能不一样。"有序" 是你对集合最危险的一个记忆点，务必改过来。

- ⚠️ **中文标点当代码符号**：笔记里 "dict的变量名。values()" 用了中文句号"。"，实际代码必须是英文点 `.`（`person.values()`）。另外 "通过item方法去去key,value" 有错别字（"去去"）。

- ⚠️ **"不重复的键" 没说全**。完整是：key 不能重复、且 key 必须是**不可变类型**（一般用字符串/数字）；value 没有限制、可以重复。你笔记里对"为什么 key 不能重复"没有理解性的表述。
- ⚠️ **集合删除写了 pop 但没说清**：`pop()` 是**随机**弹出一个元素并返回它（课件正文没讲，是在缺失数字案例里用的）；`remove()` 删除**不存在**的元素会直接报错。两者别混。
- ⚠️ **拆包只记了一句定义**。语法（`a, b = 容器`，变量个数要一致）和两个经典应用（交换变量 `c1, c2 = c2, c1`、接收函数多返回值）都没记，而这恰恰是课件第 3 章的重点和今天两个案例（字典案例 2、奇偶求和）都用到的技巧。
