- **`strip()`**：同时去除**首尾**的字符。
- **`lstrip()`**：只去除**左侧（开头）**的字符（l = left）。
- **`rstrip()`**：只去除**右侧（结尾）**的字符（r = right）。

`strip()` 是 Python 中**字符串（`str`）**最常用的内置方法之一。它的核心作用是：**去除字符串开头和结尾的指定字符（默认是空白字符）。**

这里有一个非常重要的前提：**字符串是不可变数据类型**。所以 `strip()` 不会修改原字符串，而是**返回一个处理后的新字符串**。

### re.split

split 方法按照能够匹配的子串将字符串分割后返回列表，它的使用形式如下：

```
re.split(pattern, string[, maxsplit=0, flags=0])
```

```
import re

s = "hello   world\tpython\ngood"
print(re.split(r"\s+", s))
# ['hello', 'world', 'python', 'good']
```





`re.compile(正则)` 把正则表达式**预编译成一个正则对象**，之后可以重复用这个对象去 `search` / `match` / `findall` / `split` / `sub`。

把「写好的正则 + flag」打包成一个可复用的对象。

```
import re

pattern = re.compile(r"\d+")          # 编译一次

print(pattern.findall("abc123def456"))   # ['123', '456']
print(pattern.search("abc123def"))       # <re.Match object ...>
print(pattern.split("a1b22c"))           # ['a', 'b', 'c']
print(pattern.sub("#", "a1b22c"))        # 'a#b#c'
```
