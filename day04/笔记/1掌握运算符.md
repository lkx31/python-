​	python中除是有小数点的

​	float是二进制浮点，无法精确表示**十进制**小数。金融货币市场	要用**Decimal**方法

​	Decimal:默认精度是 **28 位有效数字**,**用于“十进制浮点数”精确计算**,用字符串创建 Decimal

- `Decimal` 不是“定点数”，它仍是浮点数，只是十进制浮点。
- 需要固定两位小数时用 `quantize(Decimal('0.01'))`。
- `Decimal('0.1') == 0.1` 通常是 `False`，不要混用 `Decimal` 和 `float` 比较。
- 性能比 `float` 慢，不需要精确十进制时不必用。
- 如果要精确分数运算，可以用 `fractions.Fraction`

​	

```
from decimal import Decimal

a = Decimal('0.1')
b = Decimal('0.2')

print(a + b)  # 0.3
print(a + b == Decimal('0.3'))  # True
```



​	float对比：

```
print(0.1 + 0.2)  # 0.30000000000000004
print(0.1 + 0.2 == 0.3)  # False
```

#### rang(范围)函数方法

​	可以产生一个范围的序列，包头不包尾,**`range` 属于序列，具体说是不可变数字序列，符合序列协议，但不是容器型序列。**

```
range(stop)
range(start, stop[, step])

start: 计数从 start 开始。默认是从 0 开始。例如range（5）等价于range（0， 5）;
stop: 计数到 stop 结束，但不包括 stop。例如：range（0，5） 是 [0, 1, 2, 3, 4] 没有 5
step：步长，默认为1。例如：range（0，5） 等价于 range(0, 5, 1)
```

## 【熟悉】for循环中的else结构

​	循环可以和else配合使用，else下方缩进的代码指的是当**循环正常结束**之后要执行的代码。

​	强调：'正常结束'，非正常结束，其else中的代码时不会执行的。（如遇到break的情况）

```
for 临时变量 in 序列:
    循环体
else:
    当for循环正常结束后，返回的代码
```

​		如果 for循环是因为 **break**来退出的, 此时 else是**不会触发**执行, 程序会认为for循环是非正常结束
​        如果for循环中有**continue**, 并不会影响循环操作, 只是会跳过本次循环, 但是循环依然会完整的循环结束, 所以**else会触发执行**
