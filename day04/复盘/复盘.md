for else

else下方缩进的代码指的是当**循环正常结束**之后要执行的代码s

它最适合解决**“在循环中查找/验证某个条件，并且需要区分‘找到了’和‘完全没找到’”**的场景

```
students = ["张三", "李四", "赵六", "王五"]

for name in students:
    if name == "王五":
        print("找到了！")
        break  # 找到后立刻打断循环，此时 else 不会执行
else:
    # 如果循环完整跑完（没被 break），说明一个都没匹配上
    print("名单里没有这个人")
```
