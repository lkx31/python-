## 二、每日核心知识点总结

### day03 基础语法
- **conda（实操）**：`conda env list` 查看；`conda create -n py310 python=3.10` 创建；`conda activate py310` 激活；`conda remove -n py310 --all` 删除（**--all 不能省**，否则只卸包）
- **变量**：`=` 从右往左读；先定义后使用；同名后定义覆盖前定义
- **格式化输出**：`print('名字%s 年龄%d' % (name, age))`；`'{}'.format(name)`；`f'{name} {price:.2f}'`（推荐）；保留小数三种写法 **%.2f / {:.2f} / {x:.2f}** 背下来
- **\t**：制表符 = 一个 tab 键（4 个空格）的距离（课件 L1161 原话），**无论在开头还是中间都是制表符**
- **input**：阻塞等待；返回永远是 str，做运算前必须转换
- **类型转换**：`int(3.9)` → 3（截断）；`int('175')` 可以、`int('175.5')` 报错 → 先 float 再 int
- **eval**（课件只在转换表出现一次）：把字符串当 Python 表达式执行，危险，知道存在、别乱用

### day04 判断与循环
- **and/or 的真相**：课件说"返回布尔值"（考试按课件答），**实际返回决定结果的操作数**：`0 or 5` → 5、`3 and 4` → 4；只有 not 永远返回 bool。你的笔记例子（1 and 1 → 1）恰恰证明这点
- **if/elif 链**：按顺序判断，第一个成立的分支执行完整个链结束
- **while 三步走**：① 初始化计数器 → ② while 条件 → ③ **循环体内更新计数器**。漏第③步 = 死循环
- **for...else**：循环正常结束才执行 else；break 退出不执行；continue 不影响（照常执行）
- **边界三处最容易错**：`>=` 写成 `>`、range 包头不包尾、`count < n` 漏掉 n 本身

### day05 字符串/列表/元组
- **负步长切片（方向一致原则）**：`[::-1]` 反转可以；`[-1:-5]` 是**空串**（起点在终点右侧却用正步长）；`[-1:-5:-1]` → '9876'（起点右侧 + 负步长 ✓）；`[-5:-1:-1]` 也是**空串**（起点左侧 + 负步长 ✗）。**起点和终点谁在左、step 正负必须匹配**
- **replace/split/join**：都返回新字符串/列表，要接住；原字符串不变
- **sort**：默认升序；`sort(reverse=True)` 降序
- **元组定义**：字面量 `(1, 2)`；单元素 `(10,)`；`tuple(可迭代对象)` 转换，**不是** `tuple(元素, 元素)`

### day06 集合/字典/函数
- **集合**：**无序**、去重、可变；`{}` 是空字典，空集合只能 `set()`
- **字典 key**：唯一 + **必须是不可变类型**；`字典[key]` 查不存在的 key 报错
- **函数 return 三思考**：① return 立即退出函数 ② `return 1, 2` 返回元组 ③ 多返回值用拆包接
- **需求里的"求和"**：先想清楚返回的是**数字**还是**列表**（见第四节 day06 的三个 bug，全是这个问题）

### day07 函数参数/文件
- **形参/实参**：形参是函数内局部变量、实参是调用时传的内容，同名但作用域不同
- **缺省参数**必须写形参最后；混用时位置在前、关键字在后
- **文件模式**：r 不存在**报错**；w 不存在创建、**已存在清空**；a 不存在创建、**不清空尾部追加**
- **相对路径 vs 绝对路径**：相对 = 相对当前目录（`./` 同级、`../` 上级）；绝对 = 从盘符开始的完整路径。**和 URI/URL 没有任何关系**（那是网址概念）
- **with open(...) as f**：自动 close；图片/视频复制用 rb/wb
