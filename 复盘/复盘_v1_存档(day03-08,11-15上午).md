## 二、每日核心知识点总结

### day03 基础语法
- **环境（实操）**：Anaconda 沙箱机制 = 一个个独立环境互不冲突。`conda env list` 查看；`conda create -n py310 python=3.10` 创建；`conda activate py310` 激活；`conda remove -n py310 --all` 删除（**--all 不能省**，否则只卸载包）
- **变量（掌握）**：`变量名 = 值`，= 从右往左读；**先定义后使用**；命名 = 字母/数字/下划线，不能数字开头、不能用关键字、严格区分大小写；同名变量后定义覆盖前定义
- **七大数据类型（背）**：数值 int/float、布尔 bool、字符串 str、列表 list、元组 tuple、集合 set、字典 dict；判断类型用 `type(x)` 返回类型、`isinstance(x, 类型)` 返回 True/False
- **格式化输出（掌握，课件标注【重要】）**：
  ```python
  print('我的名字是%s，年龄%d' % (name, age))     # % 方案，%.2f 保留两位小数
  print('姓名：{}'.format(name))                   # format 方案，{:.2f}
  print(f'姓名：{name}，价格：{price:.2f}')        # f-string 方案（3.6+，课件推荐）
  ```
- **转义字符**：`\n` 换行、`\t` 制表符（tab）；print 默认结束符是 `\n`，用 `end=` 修改
- **input（掌握）**：执行到会阻塞等待输入；**返回永远是 str**，做运算前必须转换
- **类型转换（掌握）**：`int(3.5)` → 3（**截断，不是四舍五入**）；`int('3.5')` → **报错**，带小数的字符串必须先 `float()` 再 `int()`

### day04 判断与循环
- **运算符**：`//` 整除、`%` 取余、`**` 幂；比较/成员运算符返回布尔；逻辑 and/or/not（课件说法：返回布尔值，实际行为见第三节）
- **if / elif / else**：elif 不是 else if；缩进代表层级；**if/elif 链只执行第一个成立的分支**；if 嵌套先写外层再写内层
- **random.randint(1, 100)**：生成 1~100 随机数，**包头包尾**
- **while 三步走（重要）**：① 初始化计数器 → ② while 条件 → ③ 循环体里**更新计数器**（漏了第③步 = 死循环）
- **break vs continue**：break 终止**整个**循环；continue 终止**本次**循环（跳到下一次）
- **for 遍历序列**：`for 临时变量 in 序列`；`range(start, stop, step)` 包头不包尾
- **for...else**：循环**正常结束**才执行 else；**break 退出不执行 else**，continue 不影响（照常执行）

### day05 五大容器（上）
- **字符串**：单/双/三引号定义；**不可变**（方法都返回新字符串，要接住）；索引正 0 负 -1；切片 `[start:end:step]` 包头不包尾、step 可为负；`len()` 是长度不是最大索引
- **字符串方法**：`find`（找不到返回 -1）/ `index`（找不到报错）/ `replace` / `split`（返回列表）/ `join`（把序列拼成字符串）
- **列表**：可变；增 `append`/`extend`/`insert`；删 `del 列表[索引]`/`pop`（弹出并返回，默认最后一个）/`remove`（删除匹配到的第一个）；改 索引赋值/`reverse`/`sort`（默认升序，`reverse=True` 降序）；查 `index`/`count`/`in`
- **元组**：不可变，只有查；**单元素必须 `(10,)` 带逗号**，`(10)` 只是整数；`list()`/`tuple()` 互相转换

### day06 五大容器（下）+ 函数
- **集合**：**无序、去重、可变**；空集合只能用 `set()`（`{}` 是空字典）；增 `add`、删 `remove`/`pop`（随机弹出）、查 `in`；缺失数字案例用 max/min + 遍历
- **字典**：键值对，**key 唯一且必须是不可变类型**；增改同一个语法 `字典[key] = value`（存在改、不存在增）；删 `del 字典[key]`/`clear()`；查 `字典[key]`（不存在**报错**）/`keys()`/`values()`/`items()`；遍历 `for k, v in person.items()`
- **拆包**：`a, b = 容器`，**变量个数必须和元素个数一致**；两个经典应用：交换变量 `a, b = b, a`、接收多返回值
- **推导式**：`[表达式 for i in seq if 条件]`，**先执行右边 for**；集合推导式 `{...}`
- **函数**：`def 函数名(参数): ... return`；不调用不执行、先定义后使用；return 三思考：① return 立即退出函数 ② `return 1, 2` 返回的是**元组** ③ 多返回值用拆包接收
- **作用域**：函数内定义 = 局部变量（执行完销毁）；函数外 = 全局变量；函数内 `num = 20` 是**新建局部变量**不是修改全局，要改不可变类型必须 `global num`；**可变类型（list/set/dict）改内容不需要 global**

### day07 函数与文件
- **参数（掌握）**：位置传参一一对应；关键字传参不关心顺序；缺省参数**必须写在形参最后**；混用时**位置在前、关键字在后**
- **不定长参数**：`*args` 把多个位置参数**组包**成元组；`**kwargs` 把 key=value **组包**成字典；传已有容器要**解包** `f(*my_tuple, **my_dict)`；两者共存时 `*args` 在前
- **lambda（熟悉）**：`变量 = lambda 形参: 一行表达式`，两个要求：必须有返回值、函数体只能一行；经典用法 `sort(key=lambda item: item['age'])`【课件重点】
- **三元表达式**：`值1 if 条件 else 值2`
- **文件操作（掌握）**：
  ```python
  f = open('a.txt', 'w', encoding='UTF-8')   # r 读(不存在报错) / w 写(不存在创建,清空) / a 追加(不存在创建)
  f.write('内容')    # 返回写入字符数
  f.read() / f.readline() / f.readlines()    # 三种读法
  f.close()
  with open('a.txt', 'r') as f:              # with 自动关闭（课件第 4 章重点）
  ```
  - Windows 路径：`\` 是转义符会报错 → 三种方案：`/`、`\\`、`r'C:\a.txt'`
  - 中文乱码 → 加 `encoding='UTF-8'`；图片/视频复制用 `rb`/`wb` 二进制
