pymysql:pymysql是一个纯python实现的mysql客户端库,提供了python程序中操作mysql数据库的操作

pymysql使用步骤:
1.导入模块
2.创建连接
3.创建游标
4.执行sql
5.关闭游标
6.关闭连接

```
import pymysql
conn=pymysql.connect(
    host='localhost',
    user='root',
    password='root',
    port=3306,
    database="jing_dong"
)
cur=conn.cursor()
sql ="select * from goods"
result=cur.execute(sql)
print(f"查询到了多少行{result}")
data1=cur.fetchone()
print(data1)
cur.close()
conn.close()
```

fetchone:每次抓取一条，每调用一次抓取一条数据

fetchall:抓取剩余所有数据，抓取的数据放在一个元组，我们需要循环遍历一个个数据取出来

事务：要么全部成功要么全部失败

数据库的机制：mysql的数据库默认自动提交（保存在临时缓存中），代码中是默认不打开提交事务。

rollback回滚

一致性：数据前后一致；

持久性：数据不可逆，提交就不能回滚；

```
import pymysql
username=input()
password=input()

con=pymysql.connect(
    host="127.0.0.1",
    user="root",
    password="root",
    port=3306,
    database="jing_dong"
)
cur=con.cursor()
sql= f"select * from user where user=%s and pwd=%s"
params=[username,password]
result=cur.execute(sql,params)
if result:
    print("登录成功")
else:
    print("登录失败")

cur.close()
con.close()
```
