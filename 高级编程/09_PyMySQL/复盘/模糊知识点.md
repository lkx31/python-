# 模糊知识点清单（2026-11-19 PyMySQL + Redis）

> 打勾制：彻底掌握后改成 `- [x]`。详细解释见同目录 `复盘.md` 第三、四节。

## 概念类

- [ ] MySQL 命令行默认自动提交**开**；pymysql 默认**关**（所以增删改必须 commit）。未提交的修改不是"临时缓存"，是本事务内可见、别的连接不可见
- [ ] 隔离性 = 并发事务互不干扰；持久性 = 提交后永久落盘、断电不丢（不是"提交不能回滚"）
- [ ] InnoDB 支持事务，MyISAM 不支持（"必须 commit"的根）
- [ ] fetchall 返回**元组套元组**，且只取"**剩下**"的（游标只会前进）
- [ ] execute 返回值 = 影响行数，不是查询结果
- [ ] 子查询当表用（from 子查询）必须起别名

## 语法类

- [ ] 参数化占位符统一 `%s`（数字也是），参数放列表传给 execute
- [ ] `flushdb` 是清空当前库（不是"刷新"），拼写：flush + db
- [ ] `smembers` 不是 smember
- [ ] ttl 返回值：-2 键不存在 / -1 永不过期 / 正数剩余秒
- [ ] CLI 语法（`set key value`）≠ Python 方法（`r.set('k','v')`）
- [ ] redis-py 坑：`hmset` 已废弃 → `r.hset('k', mapping={...})`；`zadd` 新版必须字典 `r.zadd('k', {'成员': 分数})`
- [ ] 连 Redis 两个必带参数：`decode_responses=True`（否则 b'xxx'）+ `protocol=2`（本机 Redis 3.0.504 只支持 RESP2，redis-py 5.0+ 默认 RESP3）
- [ ] SQL 字符串用单引号，别用双引号（ANSI_QUOTES 模式会报错）
