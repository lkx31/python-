## 二、今日核心知识点总结

### 1. 子查询【上节补课，◐ 只记没练】
- 一条 SQL 的执行结果，作为另一条 SQL 的一部分：**作为条件**（`where price > (select avg(price) from goods)`）或**作为表**（`from (子查询) 别名`——当表用时**必须起别名**）。

### 2. PyMySQL 六步【必会默写，✓ 已练】
```python
import pymysql                       # 1 导入
conn = pymysql.connect(host, port, user, password, database)  # 2 连接（5 个参数）
cur = conn.cursor()                  # 3 游标
result = cur.execute(sql)            # 4 执行（返回值=影响行数，不是查询结果！）
cur.close()                          # 5 关游标
conn.close()                         # 6 关连接
```
- 取结果：`fetchone()` 一次一条（游标前进）；`fetchall()` 取**剩下**的全部，返回**元组套元组**（每行一个元组），要 for 循环拆。
- `execute` 返回的是影响行数，test.py 里 `查询到了多少行{result}` 已经验证。

### 3. 增删改 + 事务【重点，✓ 增删改练了、✗ 回滚没练】
- **InnoDB 支持事务，MyISAM 不支持**；MySQL 5.5+ 默认 InnoDB。
- 命令行客户端默认 autocommit **开**（每条自动提交）；**pymysql 连接默认 autocommit 关** → 增删改必须手动 `conn.commit()`，否则关掉连接数据就没了（未提交的修改只有本连接自己看得到）。
- 出错要 `conn.rollback()`，标准写法是把执行放进 try、回滚放进 except（老师"删"的示例）。
- ACID：**原子性**（一组操作要么全成要么全败）、**一致性**（事务前后数据都符合约束，总和守恒）、**隔离性**（并发事务互不干扰）、**持久性**（提交后永久落盘，断电也不丢）。

### 4. 登录案例 → SQL 注入 → 参数化【今日最高频考点，✓ 攻防都写了】
- 攻击：密码输入 `' or 1=1 -- ` → SQL 变成 `pwd='' or 1=1 --'`，恒真，直接登录成功（`-- ` 把后面注释掉）。
- 防御三件事缺一不可：
```python
sql = "select * from user where user=%s and pwd=%s"  # ① 占位符统一 %s（数字也是 %s）
parm = [username, password]                          # ② 参数放列表
row = cur.execute(sql, parm)                         # ③ 一起传给 execute
```

### 5. Redis 概念【✓ 笔记到位】
- 开源、**基于内存**的键值对数据库；可当数据库 / 缓存 / 消息中间件。
- 持久化两机制：**RDB 快照**（定时把内存拍照存盘）、**AOF 日志**（每条写命令追加到磁盘）。
- 5 大类型：字符串 string、哈希 hash、列表 list、集合 set、有序集合 sorted set。
- 场景：缓存系统、计数器、排行榜、（漏记的）消息队列=list、会话存储=string+过期。

### 6. 五大数据类型的 CLI 命令【✓ 命令都过了一遍】
| 类型 | 命令 | 场景 |
|---|---|---|
| string | `set/get/mset/mget`、`incr/decr` 自增自减、`setex key 秒 value` 设值+过期 | 计数器 |
| hash | `hset 名 字段 值 / hget / hmset / hmget / hkeys / hvals / hgetall / hdel` | 存对象（user:1001 分组） |
| list | `lpush/rpush`（左/右压入）、`lrange 名 起 止`、`rpoplpush 源 目标`（右弹左压，队列思想） | 消息队列 |
| set | `sadd/smembers/spop` | 去重 |
| zset | `zadd 名 分数 成员` | 排行榜 |
- 键操作：`keys *` 看所有键、`expire` 设过期、`ttl` 查剩余（**-2=键不存在，-1=永不过期**，正数=剩余秒）、`persist` 取消过期变永久、`type` 看类型、`flushdb` 清空当前库。
- 连接 Python 的 redis-py 必须 `protocol=2`：**本机 phpstudy 的 Redis 是 3.0.504，只支持 RESP2，而 redis-py 5.0+ 默认 RESP3**，不指定就连不上。

### 7. JSON 基础【✓ 为缓存实战铺垫】
- JSON 字符串本质是字符串，只是有格式；跨语言交换数据的通用格式就是字符串。
- 转字符串时一律**双引号**，只有数字和布尔不用加引号。

## 三、模糊知识点（笔记里没写清楚、容易搞错的）

- ❌ **「mysql 的数据库默认自动提交（保存在临时缓存中），代码中是默认不打开提交事务」——这句话整个是乱的，必须改**。正确版：MySQL **命令行客户端**默认自动提交开（每条 SQL 自动 commit）；**pymysql 连接**默认自动提交关，所以增删改必须手动 `conn.commit()`。未提交的修改也不是"保存在临时缓存"——它在未提交事务里：**本连接能查到，其他连接查不到，连接一关自动回滚**。这是今天事务部分的核心结论，笔记没记对。
- ⚠️ **隔离性留白了，持久性解释偏了**。笔记里"持久性：数据不可逆，提交就不能回滚"——那是"commit 不可逆"，不是持久性。持久性 = **事务提交后数据永久保存，即使断电/宕机也不丢**（靠落盘和日志保证）。隔离性 = **并发执行的事务互不干扰**，每个事务像独占数据库。把这两条补进笔记。
- ⚠️ **「InnoDB 支持事务 / MyISAM 不支持」整句漏记**。这是"为什么增删改必须 commit"的根，老师讲了，笔记里一个字都没有。
- ⚠️ **「flash db 刷新数据库」= `flushdb`**。注意它不是"刷新"，是**清空当前库所有键**（`flushall` 清空所有库），生产环境禁用级别。拼写和含义都要改。
- ⚠️ **「???代表3个占位符」——语境不明**。推测是 redis-cli 报"参数数量错误"或 `help` 输出里的占位符，这条笔记第二天自己就看不懂了，上课时确认一下补全。
- ⚠️ **「smember set1」少个 s**，命令是 `smembers set1`。
- ⚠️ **Redis 笔记全是 CLI 语法，但老师的重点代码是 Python 方法调用——两套语法混记最容易写混**。CLI：`set key value`；Python：`r.set('key', 'value')`。更关键的两个版本坑：`hmset` 在 redis-py 4.x 起已废弃（用 `r.hset('key', mapping={'a':1})`）；`zadd` 新版**必须传字典** `r.zadd('name', {'成员': 分数})`，老式 `zadd(name, score, member)` 会报错。
- ⚠️ **`decode_responses=True` 整个没记**。连 Redis 不加它，`r.get()` 返回的是字节 `b'xxx'`；加上才返回字符串。和 `protocol=2` 一样是连接必带参数，笔记里只有 protocol=2 四个字。
- ⚠️ **fetchall 描述不精确**。笔记说"抓取的数据放在一个元组"——准确是**元组套元组**（外层每个元素是一行，一行本身也是个元组）；而且是"**剩下**的"数据：游标只会往前走，先 `fetchone()` 再 `fetchall()` 就再也拿不回第一条（test.py 里恰好就是这个顺序，等于亲手体验过，把它写明白）。
- ⚠️ **子查询笔记一句话太简**："作为条件存在或者表存在"——完整说法：作为条件（where 里）或作为表（from 里，**当表用必须起别名**）。今天没有练习证据，要补。
- ⚠️ **`ttl` 笔记写"查看过去时间"**——是查看**剩余存活秒数**；-2 = 键不存在（已过期被删），-1 = 永不过期，正数 = 剩余秒。
- ⚠️ **双引号写字符串的习惯还在延续**（`"sdad"`、`"rose"`）。上期 MySQL 复盘就提过：SQL 标准是单引号，双引号在开了 `ANSI_QUOTES` 模式时会被当成列名报错。从今天的新增/修改练习开始改。

## 五、易错核对清单

- [ ] execute 的返回值是**影响行数**，不是查询结果；结果要用 fetchone/fetchall 取
- [ ] fetchall 取的是"**剩下**"的数据，先 fetchone 再 fetchall 拿不全
- [ ] InnoDB 表上增删改**必须 commit()**，否则关连接数据消失；命令行默认自动提交、pymysql 默认不提交，两者别混
- [ ] rollback 用在 try/except 的 **except 分支**
- [ ] 参数化占位符**统一 `%s`**（值即使是数字也是 %s），参数必须放列表一起传给 execute
- [ ] 连 Redis 两个必带参数：`decode_responses=True`（否则全是 `b'xxx'`）+ `protocol=2`（本机 Redis 3.0.504 只支持 RESP2）
- [ ] ttl 返回值：-2 键不存在、-1 永不过期、正数剩余秒
- [ ] `flushdb` 是**清空当前库**，不是"刷新"；生产环境禁用
- [ ] CLI 命令（`set key value`）和 Python 方法（`r.set('k','v')`）是两套语法；hmset 已废弃用 hset+mapping，zadd 新版要字典
- [ ] `rpoplpush 源 目标` = 从源**右弹**、压入目标**左**侧
