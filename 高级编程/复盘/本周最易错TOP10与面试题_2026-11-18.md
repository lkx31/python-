## 一、本周最易错 TOP10

| # | 易错点 | 错误表现（复盘证据） | 正确结论 |
|---|---|---|---|
| 1 | **量词 `{x}` 与 `{x,y}`** | 笔记里两个**正好写反**（Day07 唯二硬错误） | `{x}` = 恰好 x 次；`{x,y}` = x~y 次**含两端，不能超过 y** |
| 2 | **三个 API 的返回值差异** | api.py 复制粘贴 bug：`if result:` 判断错对象，search 失败时 `None.group()` 会直接报 AttributeError | match/search 成功→对象（要 `group()`），失败→**None**；findall 成功→列表直接打印，失败→**空列表 `[]`** |
| 3 | **贪婪 vs 非贪婪 + findall 有分组** | 只背了定义没跑案例，且"findall 有分组只返回分组内容"笔记没记 | `.*` 贪婪（两个 `<h1>` 吃成 1 条）、`.*?` 非贪婪（2 条）；`findall('<h1>(.*?)</h1>')` 只返回标题文字 |
| 4 | **转义符 `\.`** | 笔记里"转义"两个字完全没出现 | `.` 有特殊含义，匹配字面点号要加 `\`；否则 `binzi@163,com` 也会"匹配成功" |
| 5 | **修饰符 re.I / re.S** | re.I **写反**（记成"区分大小写"），re.S **完全漏记** | `re.I` = 不区分大小写（Ignore case）；`re.S` = 让 `.` 也能匹配 `\n` |
| 6 | **`^` 的双重身份 + `^$` 配合** | 两个意思各记一行但没分清前提 | `^` 在**表达式开头**=以什么开头；`^` 在 **`[]` 里面**=取反（`[^\d]==\D`）；`^...$` 配合起**限制**作用（密码位数） |
| 7 | **group by + having** | Day08 **最大缺口，完全没练** | select 裸字段要么在 group by 里要么在聚合函数里；`having` 筛分组后的结果（如 `having avg(price)<1000`） |
| 8 | **where vs having + SQL 执行顺序** | 没练（自测清单未打勾） | 四点区别：书写位置、执行时机（分组前/后）、where 后不能跟聚合、where 不能用别名；执行从 **FROM** 开始，这解释了后两点 |
| 9 | **null 三兄弟** | 代码里写成 `name=' '`（一个空格），靠 MySQL 忽略尾空格**侥幸**查对 | `null` ≠ `''` ≠ `'null'` 是三样东西，判空**只能 `is null`** |
| 10 | **delete vs truncate + 忘写 where** | 亲手制造 6 行一模一样的重复数据（无主键 + 反复插入） | delete 清空后自增**保留**，truncate **重置**；update/delete 忘写 where = **操作全表**，生产环境先 select 同样的 where 看命中行数 |

**候补（也值得记住）**：`count(*)` vs `count(字段)`（实测 15 vs 11，聚合函数忽略 null）、SQL 字符串用单引号（双引号靠 MySQL 兼容）、语句结尾缺分号（本周 3 处）、主键设计（`id int primary key auto_increment`，别拿业务字段当主键）、表起别名后必须用别名调字段。

## 二、面试题 5 道（每题 20 分）

**Q1（量词 + ^$，对应 TOP1/6）**：`{x}` 和 `{x,y}` 分别表示什么？请写一个正则：用户名由字母、数字、下划线组成，长度 6~12 位，必须以字母开头。

**Q2（三个 API，对应 TOP2）**：说清 `re.match` / `re.search` / `re.findall` 的区别（起点、返回个数、成功/失败的返回值）。下面这段代码有什么问题？
```python
import re
result = re.search("it", "abc")
print(result.group())
```

**Q3（贪婪 + 分组，对应 TOP3）**：
```python
s = '<h1>Python</h1>正文<h1>大数据</h1>'
```
`re.findall('<h1>.*</h1>', s)` 返回什么？`re.findall('<h1>.*?</h1>', s)` 返回什么？如果想直接拿到标题文字本身（不要标签），正则怎么写？

**Q4（转义 + 修饰符，对应 TOP4/5）**：写正则匹配邮箱（@ 前 4~20 位字母数字下划线，域名 `163.com`）。为什么 `163` 后面的点必须写成 `\.`？`re.I` 和 `re.S` 分别解决什么问题？

**Q5（MySQL 综合，对应 TOP7/8/9/10）**：products 表有字段 `category_id`（分类）、`price`（价格）。
1. 写 SQL：统计每个分类的商品数量和平均价格，只显示平均价格低于 1000 的分类；
2. 口述 `where` 和 `having` 的区别（至少 3 点），并说出 SQL 的执行顺序；
3. 判断某字段是否为空应该怎么写？`score = null` 行不行？`delete` 和 `truncate` 有什么区别？
