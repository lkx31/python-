## 笔记错误（必须改）

- [ ] ❌ "实体==函数" → 实体在程序中是**类/对象**，函数只是动作（方法）的实现
- [ ] ❌ "魔术方法在创建的时候会自动调用" → 各魔术方法触发时机不同：`__init__` 创建时 / `__str__` print 时 / `__del__` 删除或程序结束时
- [ ] ⚠️ `__str__` 笔记补两点：必须 return **字符串**；print(对象) 触发
- [ ] ⚠️ `__del__` 笔记补两点：实际用途（关闭文件、数据库连接）；`del` 删的是引用，销毁要等 gc
- [ ] ⚠️ "面向对象就是分类" → 面向对象是模拟现实世界的编程思想；"分类"是类的概念
- [ ] ⚠️ 笔记补命名规范：类名大驼峰、方法/变量下划线（或小驼峰）
