# 正则表达式 · 模糊知识点 / 易错点复盘

> 晚间复盘用：把掌握不牢固、容易混淆、容易出错的知识点列成清单。
> 用法：复习确认掌握后把 `- [ ]` 改成 `- [x]`；整节都掌握的可以删掉该节。
> 来源：老师课件《老师的笔记1.md》重点与易错标注 + 2026-11-16 复盘新增（笔记 4 处写错/8 处写不清 + 代码 4 个文件逐文件运行核对，见复盘.md 第三、四节）。

## 一、三个 API 易混
- [ ] **match 从头开始、search 任意位置** —— 两者都只返回第一个；findall 返回全部
- [ ] **match/search 成功返回对象** —— 要用 `group()` 提取；findall 成功返回列表直接打印
- [ ] **失败返回值不同** —— match/search 失败返回 `None`；findall 失败返回空列表 `[]`（不是 None）
- [ ] **判断方式** —— `if result:` 非空即为真
- [ ] **第三个参数是修饰符** —— 三个 API 都有：`re.match(正则, 大串, 标志位)`

## 二、单字符规则易错
- [ ] **`.` 匹配任意 1 个字符但除了 `\n`** —— 加 re.S 才能匹配 \n
- [ ] **`[ ]` 里是或者关系** —— `[bB]` 匹配 b 或 B；等价链条：`\d == [0-9] == [0123456789]`
- [ ] **记忆法** —— d=digit 数字、s=space 空白、w=word 正常词
- [ ] **`\w` 包含汉字** —— 字母、数字、下划线、汉字
- [ ] **`\s` 包含空格、`\t`、`\n`** —— 别和分组引用 `\1`/`\2` 搞混（那是引用分组，不是匹配换行）

## 三、量词易错（今天笔记错得最集中的地方）
- [ ] **`{x}` 是恰好 x 次（次数==x）** —— 不是"至少 x 次"（"至少"是 `{x,}`，课件没教，别混）
- [ ] **`{x,y}` 是 x~y 次含两端（>=x 且 <=y）** —— 不能超过 y
- [ ] **`*` 是 >=0 次、`+` 是 >=1 次、`?` 是 0 或 1 次**
- [ ] **量词管前一个字符** —— `[a-z]{3}` 是 a~z 字母恰好出现 3 次

## 四、开头结尾易错
- [ ] **`^` 在表达式开头 = 以什么开头；`^` 在 `[ ]` 里面 = 取反** —— 同一个符号两个意思，看位置（`[^\d] == \D`）
- [ ] **`^` 和 `$` 配合使用起限制作用** —— `^[a-zA-Z0-9_]{6}$` 密码必须恰好 6 位；不加 `$` 的话 `abc_123456` 也会匹配成功（只匹配前 6 位）

## 五、分组易错
- [ ] **分组编号默认从 1 开始** —— `group()` 或 `group(0)` 拿全部；`group(n)` 拿第 n 组
- [ ] **`\1`、`\2` 根据编号引用分组** —— 引用的位置必须和被引用分组匹配到**完全相同的文本**（`</\1>` 保证开闭标签一致）
- [ ] **`(?P<名字>)` 起别名、`(?P=名字)` 按名字引用** —— 起名和引用是配套的，别只记一半
- [ ] **`|` 是或者** —— 匹配左右任意一个表达式
- [ ] **findall 有分组时只返回分组内容** —— `findall('<h1>(.*?)</h1>')` 返回的是标题列表，不是整个标签（爬虫常用）

## 六、转义与特殊字符
- [ ] **`.` 等特殊字符想匹配字面本身要加 `\`** —— `\.` 才是真的点号；不转义时 `binzi@163,com` 也会"匹配成功"（`.` 能匹配逗号）

## 七、贪婪 vs 非贪婪
- [ ] **贪婪 = 匹配成功前提下尽可能多；非贪婪 = 尽可能少**
- [ ] **`*` 和 `+` 默认贪婪** —— 加 `?` 变非贪婪：`.*` → `.*?`、`.+` → `.+?`
- [ ] **`.*` 会把两个 `<h1>` 标签吃成 1 条结果，`.*?` 才是 2 条** —— 亲手跑过课件五的案例就不会忘

## 八、修饰符易错（今天笔记写错一个、漏一个）
- [ ] **`re.I` 是不区分大小写**（I = Ignore case）—— 笔记里写成了"区分大小写"，反了
- [ ] **`re.S` 让 `.` 匹配 `\n`** —— 笔记完全漏了
- [ ] **验证码场景** —— `re.findall('^a8D9$', 'A8d9', re.I)`，配 `^$` 绝对匹配

## 九、代码复盘发现的问题（2026-11-16 新增，来源：我的代码 `代码/正则表达式/*.py`）
- [ ] **`re.match(...)` 忘了赋值就 `show(result)`**（单个字符演示.py 第 18~25 行）—— `\s \S \w \W` 四个测试打印的全是上一次 `\D` 的结果，等于白测；每行都要 `result =`
- [ ] **`if result:` 复制粘贴 bug**（正则的api.py 第 10、16 行）—— search 应判断 `result2`、findall 应判断 `result3`；现在碰巧能跑，但一旦匹配失败会走错分支甚至 AttributeError
- [ ] **`print("匹配成功", {result.group()})` 的 set 花括号**（正则的分组.py、正则表达式多个匹配字符.py 的 show 函数）—— 输出显示成 `{'126'}` 集合样式，去掉 `{}`
- [ ] **注释 `#至少x次` 对应 `{3}` 是错的** —— 和笔记里 `{x}` 的错误同源，应为"恰好 3 次"
- [ ] **邮箱练习自己把需求从 `{4,20}` 改成了 `{6,}`** —— `{6,}` 是"至少 6 次"的写法，恰好又是 `{x}` 错误概念的来源，练习要按课件需求写
