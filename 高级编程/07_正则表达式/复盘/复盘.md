## 二、今日核心知识点总结

### 1. 正则概述【知道】
- 正则表达式 = 匹配**字符串中字符组合的模式**，由普通字符和特殊字符（元字符）组成
- 特点：语法可读性差，但**通用性强**（Java、PHP、Go、JavaScript 都支持，不是 Python 特有）
- 四大功能：① 数据验证（手机、邮箱、IP）② 数据检索/抓取 ③ 数据隐藏（135\*\*\*\*6235）④ 数据过滤（敏感词）
- 例子：`0\d{2}-\d{8}` 匹配座机号码

### 2. re 模块三步走 + 三个 API【掌握】
```python
import re                                   # ① 导包
result = re.match('it', 'itheima')          # ② 匹配（第三个参数可传修饰符）
print(result.group())                       # ③ 处理：从对象中 group() 提取
```
| API | 起点 | 返回 | 成功 | 失败 |
| :--- | :--- | :--- | :--- | :--- |
| `re.match` | 从头开始 | 第一个 | 匹配对象 → `group()` 提取 | `None` |
| `re.search` | 任意位置 | 第一个 | 匹配对象 → `group()` 提取 | `None` |
| `re.findall` | 任意位置 | **全部** | 列表 `[元素1, 元素2...]` 直接打印 | 空列表 `[]` |

- 判断方式：`if result:` —— **非空即为真**（对象和列表非空都算真）

### 3. 单字符规则【掌握】
- `.` 任意 1 个字符（**除了 `\n`**）
- `[ ]` 中括号中任意 1 个字符，里面是**或者关系**；`\d == [0-9] == [0123456789]`
- 记忆法：**d=digit 数字、s=space 空白、w=word 正常词**
- `\d` 数字 / `\D` 非数字；`\s` 空白(空格、`\t`、`\n`) / `\S` 非空白；`\w` 字母数字下划线汉字 / `\W` 特殊字符

### 4. 多字符规则（量词）【掌握，笔记里写错两个】
- `*` 前一个字符出现 **0 次或无限次**（>=0）
- `+` 前一个字符出现 **1 次或无限次**（>=1）
- `?` 前一个字符出现 **0 次或 1 次**
- `{x}` 前一个字符出现**恰好 x 次**（==x）← 不是"至少 x 次"
- `{x,y}` 前一个字符出现 **x 到 y 次，含两端**（>=x 且 <=y）← 不能超过 y
- 应用：`https?` 同时匹配 http 和 https；`[a-zA-Z0-9_]{6}` 匹配 6 位密码

### 5. 开头结尾【掌握】
- `^` 匹配以什么开头、`$` 匹配以什么结尾
- 一般**配合使用**起限制作用：`^[a-zA-Z0-9_]{6}$` 密码必须是 6 位，多了少了都失败
- 为什么需要：`re.match` 不加 `$` 时，`abc_123456` 也会被 `{6}` 匹配成功（只匹配前 6 位就返回）

### 6. 分组【掌握】
- `|` 匹配左右任意一个表达式（或者）
- `()` 小括号内容为一组，**默认产生从 1 开始的编号**；邮箱案例 `([a-zA-Z0-9_]{4,20})@(163|qq|sina)\.com` 中：
  - `group()` 或 `group(0)` → 所有匹配成功的数据
  - `group(1)` → 第一个分组（@ 前内容）、`group(2)` → 第二个分组（邮箱服务商）
- `\n` 根据分组编号 n **引用**对应分组：`<([a-zA-Z1-6]+)>.*</\1>` 保证开闭标签一致
- `(?P<name>)` 给分组起别名 name；`(?P=name)` 按名字引用：`<(?P<name1>...)>.*</(?P=name1)>`

### 7. 特殊匹配【掌握】
- `^` 放在 `[ ]` **里面**表示取反：`[^\d] == \D`
- **转义符**：`. * ?` 等有特殊含义的字符，想匹配字面本身要在前面加 `\`，如 `\.` 匹配真的点号
  - 案例：`^[a-zA-Z0-9_]{4,20}@163\.com$` —— 不转义的话 `binzi@163,com` 也会"匹配成功"，因为 `.` 能匹配逗号

### 8. 贪婪 vs 非贪婪【掌握】
- 贪婪：整个表达式匹配成功的前提下**尽可能多**匹配；非贪婪：**尽可能少**
- `*` 和 `+` 默认贪婪，后面加 `?` 变非贪婪：`.*` → `.*?`、`.+` → `.+?`
- 案例（课件五）：
  ```python
  my_str = '<h1>编程语言</h1>此处省略很多内容<h1>python大数据</h1>'
  re.findall('<h1>.*</h1>', my_str)    # 1 条：从头吃到最后一个 </h1>
  re.findall('<h1>.*?</h1>', my_str)   # 2 条：吃到第一个 </h1> 就停
  re.findall('<h1>(.*?)</h1>', my_str) # ['编程语言', 'python大数据'] —— 有分组时只返回分组里的内容
  ```

### 9. 修饰符【掌握，笔记里写错一个、漏一个】
- 修饰符 = 正则的**可选标志**，控制匹配模式，传在第三个参数位置
- `re.I`：设置匹配**不区分大小写**（验证码场景，配 `^$` 绝对匹配）
- `re.S`：让 `.` **真正匹配任意字符，包括 `\n`**（默认 `.` 不匹配 `\n`）

## 三、我的笔记里的模糊知识点（对比课件逐条核对）

> ⚠️ = 表述不清，❌ = 写错了。今天笔记不空，但**有 4 处硬错误 + 8 处漏记/写不清**。

- ❌ **`{x}` 写成了"至少出现 x 次且不能超过"**。课件原文：`{x}` 是**恰好 x 次**（次数==x）。"至少出现 x 次"是 `{x,}`（课件没教），不要混。
- ❌ **`{x,y}` 写成了"x 到 y 次可以超过"**。课件原文：次数 >=x **并且 <=y**，**不能超过 y**。这两个量词正好是反的，是今天最需要纠正的概念。
- ❌ **`re.I` 写反了**："设置区分大小写"应为**不区分大小写**（I = Ignore case）。验证码匹配就是靠它让 `a8D9` 能匹配 `A8d9`。
- ❌ **修饰符漏了 `re.S`**。课件明确有两个修饰符：`re.I` 不区分大小写、`re.S` 让 `.` 匹配 `\n`（默认 `.` 不匹配 `\n`）。笔记里 re.S 完全没出现。
- ⚠️ **`\d==0-9==r"\d"` 这条等价关系写混了**。正确链条是 `\d == [0-9] == [0123456789]`；`r"\d"` 不是一种等价写法，而是 **raw 字符串**（r 前缀，让 `\d` 里的反斜杠不用写成 `\\d`）—— 是"怎么写"的问题，不是"等价于谁"的问题。
- ⚠️ **`^` 写了两次但两个意思没分清**："^一扇门开头"（"以什么开头"的笔误）和"正则取反^"各占一行，但取反的关键条件是 **`^` 放在 `[ ]` 里面**才是取反（`[^\d] == \D`），课件第 5 节标题就叫"特殊匹配"。笔记里没写"在[]里面"这个前提。
- ⚠️ **`^` 和 `$` 没记"配合使用"**。分开记了开头结尾，但课件强调的用法是**配合使用起限制作用**（密码 6 位、8-10 位校验，多了少了都失败）——这是 ^$ 存在的意义，笔记漏了。
- ⚠️ **转义符 `\.` 完全没记**。课件综合练习第 3 题的核心知识点：`.` 有特殊含义（匹配任意字符），想匹配字面的点号要加 `\`。不转义时 `binzi@163,com` 会错误地"匹配成功"。
- ⚠️ **`\n` 分组引用写错了字**："更具分组编号**应用**对应分组"应为"**根据**分组编号**引用**对应分组"。另注意它和 `\s`（含 `\n` 换行）不是一回事：`\s` 是匹配空白字符，`\1`/`\2` 是引用分组。
- ⚠️ **`(?P<name>)` 只记了一半**："？p别名给分组取名字"——① 完整语法是 `(?P<名字>)`；② 还有配套的 `(?P=名字)` **按名字引用**分组，笔记没记。
- ⚠️ **group(0)/group(1)/group(2) 没记**。课件分组示例的重点：`group()`/`group(0)` 拿全部，`group(n)` 拿第 n 组（邮箱案例里分别拿到用户名和 qq/163/sina）。
- ⚠️ **三个 API 的失败返回值没记全**。笔记记了"非空即为真"的判断法，但没记：match/search 失败返回 **None**，findall 失败返回**空列表** `[]`（不是 None）。
- ⚠️ **findall 有分组时只返回分组内容**。这是贪婪/非贪婪案例里第三个知识点（`findall('<h1>(.*?)</h1>')` 只返回标题名），也是爬虫常用技巧，笔记没记。
- ⚠️ **贪婪/非贪婪记了定义但没记案例结论**：`.*` 会把两个 `<h1>` 标签**一口吃成 1 条**，`.*?` 才是 2 条 —— 这个对比是理解贪婪/非贪婪的钥匙。另外"*？和+？"里的问号写成了全角。
- ⚠️ 小笔误："match:(匹配的**子符**…)"应为"字符"；"^**一扇门**开头"应为"以什么开头"。
- ⚠️ 概述部分（正则是什么、**跨语言通用**、四大功能）笔记里没有 —— 属于"知道"级，建议补一句定义和四大功能，面试常问"正则能干什么"。
