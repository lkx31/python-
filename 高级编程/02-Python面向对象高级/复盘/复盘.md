## 二、今日核心知识点总结

### 1. 继承【掌握】
- 概念：一个类从另一个已有的类获得其成员（属性和方法），体现代码重用
- 语法：`class A(B):`；A 继承 B 所有**公共**成员（私有属性和私有方法除外）
- 相关概念：父类=基类（被继承）；子类=派生类/扩展类；**派生是动作、继承是结果**（同一件事两种说法）；扩展=子类增加自己特有成员（没有扩展继承就没意义）

### 2. 单继承与多层继承【知道】
- 单继承：一个类只继承一个父类（Java 等大多数语言的方式）
- 多层继承：A 继承 B、B 继承 C → A 自动继承 C 的公共成员（传递性）

### 3. 常见问题【易错】
- Python3 所有类默认继承 object，`class A:` / `class A(object):` / `class A():` 三种写法**完全等价**；Python2 才必须显式写（旧式类坑多，已淘汰）
- `__init__` 名字容易误写成 `__int__`

### 4. 多继承【了解，尽量少用】
- 语法：`class A(B, C):`；Python 和 C++ 支持，Java 不支持
- 两个父类有同名成员时：按继承顺序**靠前的父类优先**（本质是 MRO）
- 实际开发尽量避免多继承，命名冲突难排查

### 5. 重写（覆盖）【掌握】
- 子类定义与父类同名的属性/方法 → 子类成员生效，父类被覆盖
- 意义：父类功能不满足子类需求时扩展（Dog 汪汪叫、Cat 喵喵叫重写 call）
- **重写后父类方法还在**，只是子类先被找到；查找顺序：子类 → 父类 → … → object，找不到才报错

### 6. super()【实操】
- 作用：在子类中调用父类的属性或方法
- 三种写法：`super().方法()`（Py3 新式，最常用）、`super(当前类名, self).方法()`（完整写法）、`父类名.方法(self)`（老式）
- 经典应用：子类 `__init__` 里 `super().__init__(name, age)` 复用父类初始化，再补自己的属性

### 7. MRO【知道】
- Method Resolution Order 方法解析顺序；`类名.__mro__` 或 `类名.mro()` 查看
- 调用成员时沿 MRO 链查找：自身 → 父类 → … → object 为止

### 8. 多态【了解】
- 定义：一类事物多种形态；同一接口（函数）传入**不同对象**，执行**不同实现**，调用形式完全一致
- Python 的"伪多态"/鸭子类型：**不强制继承**，只要对象有同名方法就能统一调用（走路像鸭子、叫声像鸭子，那它就是鸭子）
- 好处：调用灵活，容易写通用代码
- 其他案例：`+` 运算符 —— 两边是数字是加法、字符串是拼接、列表是合并

### 9. 类属性【掌握】
- 定义位置：类内、方法外；被该类的**所有实例共享**；用来记录与类相关的特征（不记录具体对象特征）
- 调用：`类名.属性`（推荐）；实例也能读（`p1.count`），但**赋值会新建实例属性**遮蔽类属性
- 经典应用：计数器 `Person.count += 1` 统计创建了多少个对象

### 10. 类方法【掌握】
- `@classmethod` 装饰；第一个参数 `cls`（表示当前类本身，解释器自动传）
- 调用：`类名.方法名()`，不需要实例化
- 用途：操作类属性（类属性设为私有后，通过类方法提供访问接口，符合封装）
- `cls` 自动绑定子类，被继承后扩展性强

### 11. 静态方法【掌握】
- `@staticmethod` 装饰；**无默认参数**（不需要 self/cls）
- 本质是普通函数，只是挂靠在类里；不指向类也不指向对象；要访问类属性必须显式写 `类名.属性`
- 适用：与类弱相关的工具函数（打印菜单、帮助信息）

### 12. 五种成员对比【考点，背表格】
| 类型 | 定义位置 | 第一个参数 | 调用方式 | 访问范围 |
| --- | --- | --- | --- | --- |
| 实例属性 | __init__ 或方法内 | - | 对象.属性 | 每个对象独有 |
| 实例方法 | 类内无装饰器 | self | 对象.方法() | 实例属性 + 类属性 |
| 类属性 | 类内方法外 | - | 类名.属性 | 所有对象共享 |
| 类方法 | @classmethod | cls | 类名.方法() | 只能类属性 |
| 静态方法 | @staticmethod | 无 | 类名.方法() | 都不能直接访问 |

### 13. Game 综合案例【实操】
- 类属性 top_score 记录历史最高分；实例属性 player_name 记录玩家名（__init__ 里设）
- show_help 静态方法、show_top_score 类方法、start_game 实例方法 —— 一题练全三种方法

### 14. 自学任务【课件标注"自学"】
- 抽象类：`@abstractmethod`（是什么/能做什么/怎么做）
- `@property` / `@xxx.setter` / `@xxx.deleter`
