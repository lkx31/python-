导入惯例：`import numpy as np`（后面所有代码都按这个缩写走）。

### 2.2 创建 ndarray：六种方式

| 方式 | 代码 | 记忆点 |
|------|------|--------|
| 从列表 | `np.array([1,2,3])` / `np.array([[1,2],[3,4]])` | 多维注意维度对齐 |
| 全 0 / 全 1 | `np.zeros((3,4))` / `np.ones((2,3))` | **传形状元组 `(3,4)`，不是 `np.zeros(3,4)`** |
| 等差序列 | `np.arange(0,10,2)` | 左闭右开，步长 2 |
| 等分 | `np.linspace(0,1,5)` | 0~1 之间**等分 5 份**（含端点） |
| 随机-均匀 | `np.random.rand(3,3)` | [0,1) 均匀分布 |
| 随机-正态 | `np.random.randn(3,3)` | 标准正态分布（别和 `rand` 搞混） |
| 随机-整数 | `np.random.randint(...)` | 笔记只留了名字，自己试出参数 |

### 2.3 四个属性（必背）

`arr.ndim`（维度数）/ `arr.shape`（形状元组）/ `arr.size`（元素总数）/ `arr.dtype`（数据类型）

### 2.4 索引和切片

- 二维用逗号分隔行列：`arr[0,0]` 第一个元素、`arr[-1]` 最后一行、`arr[:,1]` 所有行的第二列
- 切片带步长：`arr[:2,:2]` 前两行前两列、`arr[::2,::2]` 行列都隔一个取一个
- **布尔索引**：`arr[arr > 5]` 直接一步筛出大于 5 的元素
- ⚠️ NumPy 切片是**视图不是副本**，修改切片会改动原数组（和列表切片习惯不同！）

### 2.5 形状操作

`reshape(3,4)`（元素总数必须一致）/ `.T` 转置 / `flatten()` 展平 / `np.resize()`

### 2.6 数学运算（明天第一个高频考点）

- **元素级运算**：`+ - * / **`、比较运算 `a > 2`、`a == b`
- **矩阵乘法 `np.dot()`**（和 `*` 完全两码事）：
  - 维度必须匹配：`(2,3)` @ `(3,2)` = `(2,2)`；`(2,3)` @ `(2,3)` 直接报错
  - **矩阵乘法不满足交换律**（笔记里用 `matrix_b.T` 正反各算了一遍做对比，重点盯）
- 统计运算：`np.sum`（`axis=0` 沿列方向/每列总和，`axis=1` 每行总和）、`np.mean/std/var`、`np.min/max`、`np.argmin/argmax`（返回**索引**）

### 2.7 广播机制

- 形状不同也能运算：`(3,3)` 数组 + `(3,)` 向量 → 自动广播到每一行；`(3,1)` 列向量 × `(3,3)` → 广播到每一列
- 规则一句话：**最后一维相等，或其中一个是 1**

## 3. Pandas —— 明日绝对主角

导入惯例：`import pandas as pd`

### 3.1 Series：一维带标签数组

- 三种创建：从列表（自动 0,1,2 索引）/ 从字典（key 变索引）/ 指定 `index=['x','y','z']`
- 两个属性：`s.values`（值）/ `s.index`（索引）

### 3.2 DataFrame：二维表格（三种创建方式，扩展代码是重点）

| 方式 | 代码骨架 | 记忆点 |
|------|---------|--------|
| 字典 | `pd.DataFrame({'姓名':[...], '年龄':[...]})` | **列角度**，key 自动是列名 |
| 列表 | `pd.DataFrame(data_list, columns=['id','name','price'])` | **行角度**，必须手动指定 columns |
| 读文件 | `pd.read_csv('data/测试数据.txt', sep=',', names=['id','name','price'])` | 没有表头时用 `names` 补列名 |

- 基本信息四件套：`df.shape` / `df.columns` / `df.index` / `df.dtypes`
- 查看数据：`head(3)` 前几行 / `tail(3)` 后几行 / `describe()` 描述性统计 / `info()`

### 3.3 数据选择（明天最绕、最易错的部分，重点预习）

| 写法 | 含义 | 易错点 |
|------|------|--------|
| `df['姓名']` | 选单列 | 返回 Series |
| `df[['姓名','年龄']]` | 选多列 | **必须是列表**，不是两个参数 |
| `df.loc['s1']` | 按**标签**选行 | loc = label |
| `df.iloc[0]` | 按**位置**选行 | iloc = index 位置 |
| `df.loc[:, '姓名']` / `df.iloc[:, 0]` | 行列二维写法 | `[行, 列]` 逗号隔开 |
| `df.loc[:, '姓名':'城市']` | 标签切片 | **左闭右闭** |
| `df.iloc[:, 0:3]` | 位置切片 | **左闭右开**（和 Python 一致） |

> 一句话区分：`loc` 看标签名（切片闭区间）、`iloc` 看位置（切片开区间），两者不可混用。

### 3.4 筛选和排序

- 条件筛选：`df[df['年龄'] > 30]`（和 NumPy 布尔索引一个思路）
- query 方法：`df.query('年龄 > 28 and 工资 < 7000')`（字符串里写 SQL 风格条件）
- 排序：`df.sort_values('工资', ascending=False)` 降序；多列 `df.sort_values(['部门','工资'], ascending=[True, False])`（部门和工资分别指定升降序）

### 3.5 缺失值处理

- 检查：`df.isnull().sum()`（每列缺失个数）/ `df.notnull().sum()`
- 删除：`df.dropna()`（默认删含缺失值的**行**）/ `df.dropna(how='all')`（只删全空的行/列）
- 填充：`df.fillna(0)` 填固定值 / `df.fillna(df.mean())` 填均值 / `fillna(method='ffill')` 用**前一个值**填 / `bfill` 用**后一个值**填

### 3.6 分组聚合（数据分析的灵魂操作）

- `df.groupby('产品')['销售额'].sum()` → 按产品分组求总销售额
- `df.groupby(['产品','地区'])['销售额'].agg(['sum','mean'])` → 多列分组 + 一次算多个统计量
- 数据透视表：`df.pivot_table(index='产品', values='销售额', aggfunc='sum')`（默认 aggfunc 是 `mean`）

## 4. Matplotlib —— 画图展示

导入惯例：`import matplotlib.pyplot as plt`

### 4.1 三行固定配置（缺一行就出问题，必须默写）

```python
import matplotlib
matplotlib.use('TkAgg')                       # 新版本不指定后端 → 图显示不出来
plt.rcParams['font.sans-serif'] = ['SimHei']  # 不设 → 中文标题乱码
plt.rcParams['axes.unicode_minus'] = False    # 不设 → 负号显示成方块
```

### 4.2 折线图六步走（模板化记忆）

```python
plt.figure(figsize=(8, 5))        # 画布大小，传元组，单位英寸
plt.plot(x, y, color='blue')      # 折线（bar 换成柱状？笔记留了注释，自己试）
plt.title("折线图示例")            # 中文标题（依赖 4.1 配置）
plt.xlabel("X轴") / plt.ylabel("Y轴")
plt.grid()                        # 网格
plt.show()                        # 必须最后调用
```

### 4.3 散点图

- 数据加随机噪声：`y = x * 2 + np.random.randn(50) * 0.8`
- `np.random.seed(42)` 固定随机种子，保证每次结果可复现
- 核心就一句 `plt.scatter(x, y, color='red')`，其余与折线图相同

## 8. 易错预警（提前打预防针，课堂重点盯）

| # | 坑 | 后果 | 对策 |
|---|----|------|------|
| 1 | `np.zeros(3,4)` 分开传参 | 报错 | 形状必须传元组 `(3,4)` |
| 2 | `rand` / `randn` 不分 | 分布用错 | rand = [0,1) 均匀，randn = 标准正态 |
| 3 | 以为 NumPy 切片是副本 | 改切片把原数组也改了 | 切片是视图，需要副本用 `.copy()` |
| 4 | `reshape` 前后元素总数不一致 | 报错 | 重塑前先 `arr.size` 算清楚 |
| 5 | 用 `*` 做矩阵乘法 | 算成元素级乘积 | 矩阵乘法用 `np.dot`，且检查维度 |
| 6 | loc / iloc 混用 | 取错行列 | loc 看标签（切片闭区间），iloc 看位置（开区间） |
| 7 | `df['a','b']` 选多列 | 报错 | 多列传列表 `df[['a','b']]` |
| 8 | `dropna()` 以为删的是列 | 数据被整行删掉 | 默认删行；删列需 `axis=1` |
| 9 | 忘配 TkAgg 后端 | 图不显示 | 三行配置每次画图前都写上 |
| 10 | 中文标题乱码 / 负号变方块 | 图没法看 | `SimHei` + `axes.unicode_minus=False` |
| 11 | `pivot_table` 不写 `aggfunc` | 默认算 mean 不是 sum | 求总和显式写 `aggfunc='sum'` |
| 12 | 读 CSV 忘写 `encoding='gbk'` | UnicodeDecodeError | 中文数据文件先试 gbk |
