# 面向对象笔记整理

## 1. 面向过程与面向对象

### 面向过程

- 以过程/函数为中心。
- 常采用自顶向下、逐步求精的方式分析问题。
- 把问题拆成步骤，按顺序实现。

### 面向对象 OOP

- 以对象为中心，尽可能模拟现实世界或问题领域。
- 核心：把**属性（数据）**和**方法（行为）**组织到对象中。
- 不是简单的“分类”，而是一种建模和编程思想。

> 口号“万物皆对象”可以理解为：在面向对象建模中，很多实体和概念都可以抽象为对象。

------

## 2. 对象与类

### 对象 object

- 对象是类的实例。
- 在程序中，对象是内存中的数据结构。
- 对象可以对应现实实体，也可以表示抽象概念。

### 实体、属性、方法

- 实体的特征信息 → 对象中的**属性**。
- 实体的动作/行为 → 对象中的**方法**。
- 属性通常是名词性信息，如姓名、身高、体重。
- 方法通常是动词性行为，如跑、吃、计算。

> 注意：实体不等于函数。实体在程序中通常通过类/对象来抽象。

### 类 class

- 类是对具有相同属性和方法的一组对象的抽象。
- 类像模板，对象是按类创建出来的实例。
- 编程中通常先定义类，再创建对象。
- 类定义后，可以暂时没有对象实例。

### 实例化

python

```
对象变量 = 类名()
```



示例：

python

```
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def say(self):
        print(f"我是{self.name}，今年{self.age}岁")

p = Person("小明", 18)
p.say()
```



------

## 3. self

- `self` 表示当前调用该方法的对象。
- `self` 不是关键字，只是约定名称。
- 调用实例方法时不需要手动传 `self`，Python 会自动传入。

python

```
class Person:
    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)

p = Person("小明")
p.show()  # 自动把 p 传给 self
```



------

## 4. 属性与方法的访问

- 访问属性：`对象.属性`
- 调用方法：`对象.方法()`

python

```
p.name
p.say()
```



注意：

- `对象.属性` 是访问属性，不是定义属性。
- 实例属性通常在 `__init__` 中定义：`self.属性 = 值`。
- 也可以定义类属性，但类属性属于类，实例属性属于具体对象。

## 5. 魔术方法

魔术方法不需要显式调用，而是在特定时机自动触发。

### `__init__`

- 创建对象并初始化时自动执行。
- 常用于给对象赋值属性。

python

```
class Person:
    def __init__(self, name):
        self.name = name
```



### `__str__`

- 在 `print(对象)` 或 `str(对象)` 时调用。
- 必须返回字符串。
- 用于把对象转换成更可读的字符串，而不是默认地址信息。

python

```
class Person:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"Person(name={self.name})"
```



### `__del__`

- 与对象销毁相关，但**不保证一定执行**。
- 程序异常终止、解释器退出、循环引用等情况下，可能不调用或延迟调用。
- 不应把关键资源释放完全依赖 `__del__`。

------

## 6. 对象的生命周期

- 对象从创建到销毁。
- 通常需要先实例化对象。
- `__init__` 在创建/初始化时执行。
- `__del__` 不保证在所有销毁场景下执行。

------

## 7. 私有属性和方法

Python 中没有严格意义上的私有，只有名称改写。

- 属性或方法名前加两个下划线：`__name`
- Python 会进行名称改写，例如 `__name` 可能变成 `_类名__name`
- 外部仍可通过改写后的名字访问，但不建议。
- 更推荐通过方法或 `property` 提供受控访问。

python

```
class Person:
    def __init__(self):
        self.__age = 18

    def get_age(self):
        return self.__age
```

## 8. 面向对象三大特性

### 封装

- 隐藏内部实现细节，对外提供接口。
- 不是简单“把属性和函数包起来”。
- 目的是降低耦合、保护数据、方便维护。

### 继承

- 子类可以复用父类的属性和方法。
- 子类可以扩展新功能，也可以重写父类方法。
- 不要为了复用而滥用继承。

### 多态

- 同一接口/方法名，在不同对象上有不同实现或响应。
- Python 中多态常通过动态类型、鸭子类型体现，不一定要求继承。

## 三、建议你重点改掉的三句话

1. **“实体 == 函数”** → 改为：**实体在程序中通常抽象为类/对象，函数用于表示行为/方法。**
2. **“魔术方法在创建的时候会自动调用”** → 改为：**魔术方法在特定时机自动触发，不同魔术方法触发时机不同。**
3. **“异常终止会销毁对象但不执行 \**del\**”** → 改为：**`__del__` 不保证执行，异常终止和解释器退出等场景下可能不调用。**
