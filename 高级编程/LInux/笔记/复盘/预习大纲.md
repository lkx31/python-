## 1. 概念铺垫（了解，别跳过动机）

- **为什么学 Linux**：Windows 不适合做服务器（卡），Linux 稳定，是服务器主流系统。
- 计算机组成：冯·诺依曼体系（输入设备 / 输出设备 / 运算器 / 控制器 / 存储器）；软件分系统软件（操作系统）和应用软件。
- **操作系统承上启下**：硬件与应用软件之间的桥梁。
- Linux：1991 年诞生，创始人**林纳斯·托瓦兹**，吉祥物小企鹅；本次课程使用 **CentOS 7**。

## 2. 环境搭建（明天第一半场，尽量课前完成）

### 2.1 虚拟网络三模式（必考概念，对比记忆）

| 模式 | 上网方式 | 一句话 |
|------|---------|--------|
| **NAT【推荐】** | 把 Windows 当路由器 | 借 Windows 电脑上网 |
| 桥接 | 接入 Windows 所在网络 | 借 Windows 用的路由器上网 |
| 仅主机 | 不能上网 | 只能和 Windows 互通 |

### 2.2 搭建检查清单（按顺序走）

1. 装 VMware → 必须检查虚拟网卡：`win + r` 输入 **ncpa.cpl**，看是否生成 **VMnet1 和 VMnet8**，没有 = 没装成功。
2. 网段约定：**192.168.88.x**，网关 **192.168.88.2**；首次虚拟机 IP 自动分配 **192.168.88.3**。
3. 概念：**DNS** 做域名 ↔ IP 转换；**域名 = IP 的别名**（www.baidu.com → 14.119.104.254 等）。
4. 创建虚拟机（纯净版要点）：内存 2GB、处理器 2 核、磁盘 20–40GB 单文件、主机名 **node1**、root 密码 123456。
5. **快照**：把拍照当时的全部状态定格，可恢复；**关机状态拍最省空间**。

### 2.3 验证标准（两条命令 + 一个工具）

- 看 IP：Windows 用 `ipconfig`，Linux 用 `ifconfig`。
- 看联网：`ping www.baidu.com`（前提是本地电脑联网，否则请求超时）。
- FinalShell：安装 → 新建连接（IP + root + 密码）→ 上传文件**直接拖拽即可**。

## 3. Linux 命令（明天核心，全部要会敲）

### 3.1 目录结构（与 Windows 对比记忆）

```
Windows：多个根目录  C:/  D:/  E:/
Linux  ：只有一个根目录  /  ，树型结构
```

- 绝对路径中**第一个 `/` 是根目录**，后面的 `/` 是目录间隔符，如 `/home/binzi`。
- `.` 当前目录（可省略）、`..` 上一层目录。
- **家目录**：普通用户 `/home/用户名`，root 用户 `/root`；快速回家 `cd ~`（`~` 可省略）。
- 重点目录：`/home` 普通用户家目录、`/root` root 家目录、`/etc` 系统配置、`/bin` 常用命令、`/usr` 软件安装（类似 Program Files）、`/tmp` 回收站。

### 3.2 命令通用格式（默写）

```
command [-options] [parameter]
命令名   选项(可省略)    参数(0 个/1 个/多个)
```

### 3.3 高频命令速查（9 类，先背全名）

| 类别 | 命令 | 关键参数与记忆点 |
|------|------|-----------------|
| ① 基础导航 | `ls` / `cd` / `pwd` / `clear` | `ls -a` 显示隐藏（`.` 开头）`-l` 详细信息（=`ll`）`-h` 配合 `-l` 人性化大小；`clear` 快捷键 ctrl+L |
| ② 小技巧 | — | **tab 补全**、`history` 或 ↑↓ 翻历史命令 |
| ③ 路径 | 绝对 / 相对 | 绝对以 `/` 开头，相对以当前目录为起点（`./` `../`），后续常用相对 |
| ④ 帮助 | `--help` / `man` | `ls --help` 帮助文档；`man ls` 详细手册 |
| ⑤ 创建 | `mkdir` / `touch` | `mkdir -p` 自动创建不存在的父目录（多层嵌套）；`touch` 建文件（一般用 vim） |
| ⑥ 查看 | `cat` / `less` / `head` / `tail` | `cat -n` 行号（小文件）；`less` 空格翻页/回车一行/b 上一页/q 退出；`head/tail -num` 默认 10 行；**`tail -f` 循环读取 = 实时看日志** |
| ⑦ 复制移动删除 | `cp` / `mv` / `rm` | `cp -r` 递归复制文件夹，**源文件还在**；`mv` 相当于剪切，**源文件没了**；`rm -r` 删文件夹、`rm -f` 强制 |
| ⑧ echo + 重定向 | `echo` `>` `>>` | `>` 覆盖写入、`>>` 追加写入；`echo 'hello' >> h.txt` |
| ⑨ 打包/进程 | `tar` / `find` / `ps` / `kill` | 见下方 tar 专项；`find 路径 -name 文件名`（`*` 通配）；`ps -ef | grep -i`；`kill -9 pid`；`&` 放命令尾 = 后台运行 |

### 3.4 tar 专项（-f 永远放最后）

```
压缩: tar -zcvf 包名.tar.gz 文件/目录...
解压: tar -zxvf 包名.tar.gz -C 目标位置
参数: -c 压缩  -x 解压  -v 显示过程  -z gzip  -f 文件名(必须最后一个)  -C 解压目的地
```

### 3.5 易混点（课堂重点盯）

- **cp vs mv**：cp 复制后源文件仍在，mv 移动后源文件消失。
- **mv 的坑**：目标目录不存在时不会报错，会当成"改名"处理——移动前先 `mkdir` 好目录。
- **tail -f** 循环读取，是查日志的招牌命令。

## 4. vi/vim 编辑器（明天核心）

### 4.1 概述与三种模式（转换链必须背熟）

```
vi  = Windows 记事本
vim = notepad++（编辑器之神）
```

```
vim 文件名  →  命令模式  →按 i→  插入模式(编辑)  →ESC→  命令模式  →输入 :→  底线命令模式
```

- 文件**不存在会自动创建**，编辑完 `:wq` 保存即可。

### 4.2 保存退出命令

`w` 保存 ｜ `q` 退出 ｜ `q!` 强制退出（不保存）｜ `wq` 保存并退出 ｜ `wq!` 强制保存并退出

### 4.3 入门案例

`vi hello.py` → `i` 输入 `print('hello ai大模型')` → ESC → `:wq` → 再 `vim hello.py` 验证内容 → `q` 退出。

### 4.4 典型应用：修改固定 IP（明天最高频实操）

1. `vim /etc/sysconfig/network-scripts/ifcfg-ens33`
2. 改两处：
   - `BOOTPROTO="dhcp"` → **`"static"`**
   - 文件末尾追加：`IPADDR="192.168.88.3"`、`NETMASK="255.255.255.0"`、`GATEWAY="192.168.88.2"`、`DNS1="8.8.8.8"`、`DNS2="114.114.114.114"`
3. 重启网络（二选一）：旧版 `service network restart` ｜ 新版 `systemctl restart network`
4. 改完 IP 后，**FinalShell 必须用新 IP 重新连接**。

## 5. 扩展了解：权限与备份

### 5.1 权限（chmod 三种写法）

- `ll` 看到的符号：第 1 位 `d` 文件夹 / `-` 文件 / `l` 链接（快捷方式）；后 9 位三组 = 属主 **user** / 属组 **group** / 其他 **other**，每组 `rwx`（读/写/执行）。
- 写法一：`chmod u+rwx 文件`（u / g / o，+ / -）
- 写法二：`chmod u=rwx 文件`
- 写法三（数字）：`r=4`、`w=2`、`x=1` → `chmod 777 文件`；例：`chmod 652` = **rw-r-x-w-**

## 8. 易错预警（提前打预防针，课堂重点盯）

| # | 坑 | 后果 | 对策 |
|---|----|------|------|
| 1 | 装完 VMware 不检查网卡 | 后面网络配置全白搭 | `ncpa.cpl` 确认 VMnet1/VMnet8 |
| 2 | mv 目标目录不存在 | 静默变成改文件名 | 先 `mkdir` 目标目录再 mv |
| 3 | 删文件夹忘加 `-r` | 删不掉 | 文件夹用 `rm -r`；`rm -rf` 危险慎用 |
| 4 | tar 的 `-f` 不在最后 | 命令报错 | `-f` 永远放所有选项最后 |
| 5 | vim 里编辑完不会退出 | 卡在编辑器里 | ESC → `:wq` |
| 6 | 改完固定 IP 不重启网络 | 配置不生效 | `service/systemctl restart network` |
| 7 | 改 IP 后还用旧 IP 连 FinalShell | 连不上 | 用新 IP 重新连接 |
| 8 | 开机状态拍快照 | 占用空间大 | 关机后再拍快照 |
