## 二、re 模块与三大匹配方式

### 2.1 re 模块使用三大步（必背）
1. **导包**：`import re`
2. **匹配**：`结果 = re.match / search / findall(正则表达式, 大字符串, 标志位)`
3. **处理数据**：match/search 用 `group()` 提取；findall 直接得到列表

### 2.2 三种匹配方式对比表（明天要能自己复述）

| 对比项 | match | search | findall |
| :--- | :--- | :--- | :--- |
| 搜索范围 | 只从**开头** | **整个**字符串 | **整个**字符串 |
| 返回数量 | 只返回第一个 | 只返回第一个 | **所有**匹配 |
| 匹配成功 | 匹配对象（`group()` 提取） | 匹配对象（`group()` 提取） | 列表 `[元素1, 元素2...]` |
| 匹配失败 | `None` | `None` | 空列表 `[]` |
| 适用场景 | 验证开头规则 | 找中间出现的内容 | 一次找出全部 |

```python
# 预习试写：同一正则，三种方式的差异
import re
print(re.match('itheima', 'www.itheima.com'))    # None（不在开头）
print(re.search('itheima', 'www.itheima.com'))   # 匹配对象 → group() 取出
print(re.findall('itheima', 'www.itheimaitheima.com'))  # ['itheima', 'itheima']
# 处理：非空即为真(True)
```

## 三、匹配规则一：单个字符（元字符表）

> 记忆方式：**d** = digit 数字，**s** = space 空白，**w** = word 词

| 符号 | 含义 | 补充 |
| :--- | :--- | :--- |
| `.` | 任意 1 个字符（**除了 `\n`**） | 想要匹配 `.` 本身要转义 `\.` |
| `[]` | 中括号中任意 1 个字符 | 内容是**或者**关系，如 `[bB]`、`[0-9]` |
| `\d` | 任意 1 个数字 0-9 | `\d == [0-9] == [0123456789]` |
| `\D` | 非数字 | |
| `\s` | 任意 1 个空白（空格、`\t`、`\n`） | |
| `\S` | 非空白 | |
| `\w` | 任意 1 个正常词（字母、数字、下划线、**汉字**） | |
| `\W` | 非正常词（特殊字符） | |

```python
# 预习试写：. 不能匹配 \n（明天课上验证）
re.match('binzi_666.帅气', 'binzi_666\n帅气')   # 匹配失败，因为 . 不能匹配 \n
```

## 四、匹配规则二：多个字符（量词）

> 量词作用于**前一个字符**，控制它出现的次数

| 符号 | 次数范围 | 记忆 |
| :--- | :--- | :--- |
| `*` | ≥ 0 次 | 可有可无，无限 |
| `+` | ≥ 1 次 | 至少 1 个 |
| `?` | 0 或 1 次 | 有或没有 |
| `{x}` | 恰好 x 次 | 精确个数 |
| `{x,y}` | x 到 y 次（含两端） | 区间 |

```python
# 预习试写：典型用例
re.match('[A-Z].*', 'Binzi666_帅气')     # 首字母大写，后面任意
re.match('t.*o', 'to')                  # 成功：* 允许 0 个
re.match('t.+o', 'to')                  # 失败：+ 要求至少 1 个
re.match('https?', 'http')              # s 可有可无 → http/https 都行
re.match('binzi_\d{3}_帅气', 'binzi_888_帅气')  # 恰好 3 位数字
re.match('[a-zA-Z0-9_]{8,10}', 'abc_ABC_123_456')  # ⚠️ 有漏洞！见下节
```

## 五、匹配规则三：开头结尾 + 特殊匹配

### 5.1 `^` 和 `$`（键盘：shift+6 / shift+4）
- `^`：匹配以什么**开头**；`$`：匹配以什么**结尾**
- **一般配合使用，起到「限制」作用** —— 修上节 `{x,y}` 的漏洞：

```python
# ⚠️ 漏洞：只写 {8,10} 时，12 位的密码取前 10 位也能匹配成功
re.match('[a-zA-Z0-9_]{8,10}', 'abc_ABC_123_456')    # 成功（有漏洞）
# ✅ 加 ^ $ 限制整体长度
re.match('^[a-zA-Z0-9_]{8,10}$', 'abc_ABC_123_456')  # 失败
re.match('^[a-zA-Z0-9_]{8,10}$', 'abcABC123')        # 成功
```

### 5.2 特殊匹配：`[^]` 取反
- `^` 放到 `[]` **里面**表示取反：`[^\d] == [\D] == \D`

## 六、匹配规则四：分组

| 符号 | 含义 |
| :--- | :--- |
| `|` | 匹配左右任意一个表达式（**或者**），如 `163|qq|sina` |
| `()` | 小括号中内容为一组，默认产生**从 1 开始的编号** |
| `\n` | 根据分组编号 n **引用**对应的分组（如 `\1`） |
| `(?P<name>)` | 给分组**起别名** name |
| `(?P=name)` | 根据分组名 **引用**对应的分组 |

```python
# 预习试写：邮箱 + 分组取值
result = re.match('([a-zA-Z0-9_]{4,20})@(163|qq|sina)\.com', 'binzi@qq.com')
result.group(0)  # 所有匹配成功的数据
result.group(1)  # 第 1 组：binzi
result.group(2)  # 第 2 组：qq

# 预习试写：HTML 标签配对（引用分组）
re.match('<([a-zA-Z1-6]+)>.*</\\1>', '<html>标签内容</html>')        # 编号引用
re.match('<(?P<name1>[a-zA-Z1-6]+)>.*</(?P=name1)>', '<html>标签内容</html>')  # 别名引用
```

## 七、贪婪模式 vs 非贪婪模式（爬虫重点）

- **贪婪**（默认）：匹配成功的前提下，**尽可能多**地匹配 —— `.*`  `. +`
- **非贪婪**：匹配成功的前提下，**尽可能少**地匹配 —— 在量词后加 `?` → `.*?`  `. +?`

```python
# 预习试写：观察两种结果的数量差异
my_str = '<h1>编程语言</h1>此处省略很多内容<h1>python大数据</h1>'

re.findall('<h1>.*</h1>', my_str)    # 贪婪：1 个结果（整段全吃）
re.findall('<h1>.*?</h1>', my_str)   # 非贪婪：2 个结果（一对一对取）

# ⭐ 重要知识点：findall 匹配中如果有分组，只把分组里的内容放进列表返回
re.findall('<h1>(.*?)</h1>', my_str) # ['编程语言', 'python大数据']
```

## 八、正则修饰符（第三个参数）

| 修饰符 | 作用 | 典型场景 |
| :--- | :--- | :--- |
| `re.I` | 不区分大小写 | 验证码匹配（配合 `^ $` 绝对匹配） |
| `re.S` | 让 `.` 真正匹配任意字符，**包含 `\n`** | 跨行文本 |

```python
# 预习试写
re.findall('^a8D9$', 'A8d9', re.I)              # ['A8d9'] 忽略大小写
re.match('.{7}', '123\n456\n789')               # None（. 不匹配 \n）
re.match('.{7}', '123\n456\n789', re.S).group() # '123\n456'
```

## 十二、易错点预警（来自老师笔记的坑）

1. **`.` 不匹配 `\n`**：跨行匹配要加 `re.S`
2. **量词不限制整体长度**：`[a-zA-Z0-9_]{8,10}` 对 12 位密码也能匹配前 10 位 → 必须加 `^ $`
3. **忘记转义**：邮箱 `.com` 里的 `.` 是元字符，`binzi@163,com` 都能匹配成功 → 用 `\.`
4. **findall + 分组**：返回的不是整个匹配，而是分组里的内容（爬虫取标题常用这个特性）
5. **match 只能从头匹配**：找中间的内容用 search 或 findall
6. **贪婪是默认的**：`<h1>.*</h1>` 会把两段标题连成一段全吃掉 → 用 `.*?`
7. **match/search 失败返回 `None`**：要 `group()` 前先判断（非空即为真）
8. **分组编号从 1 开始**：`group(0)` 是全部内容，`group(1)` 才是第 1 组
